macOS · 파일 매니저

Windows 탐색기의 경험,
macOS에서 그대로.

Explorer for Mac은 Windows에서 넘어온 사용자를 위한 네이티브 macOS 파일 매니저입니다. Finder에 적응하느라 애쓰지 마세요 — 손에 익은 그 구조 그대로 파일을 다룰 수 있습니다.

  • 항상 보이는 폴더 트리 + 탭 + 주소 표시줄 — 탐색기 그대로의 화면 구조
  • 정보 밀도 높은 Details 뷰와 6가지 보기 모드, 폴더 크기 표시
  • 잘라내기·복사·붙여넣기, F2 이름 바꾸기 — Windows 단축키 그대로
  • 파일 안전 최우선: 휴지통 기본 삭제, 무음 실패 없는 명확한 안내
  • 미리보기 패널, Finder 태그, 외장 디스크 추출까지 — Finder 없이 끝
  • 완전 오프라인 동작 · 텔레메트리 없음

버전 1.0.0 · macOS 14 Sonoma 이상 · Apple Silicon & Intel

설치 안내

1

내려받기

위의 다운로드 버튼으로 DMG 파일을 내려받아 엽니다.

2

Applications로 드래그

열린 창에서 Explorer 아이콘을 Applications 폴더로 끌어다 놓으면 설치 끝입니다.

3

폴더 접근 허용

첫 실행 시 macOS가 데스크톱·문서·다운로드 폴더 접근을 물어봅니다. 파일 탐색을 위한 표준 권한이며, 시스템 설정 ▸ 개인정보 보호 및 보안에서 언제든 바꿀 수 있습니다.

프라이버시. Explorer for Mac은 완전히 오프라인으로 동작하며, 파일 이름·경로·사용 데이터를 포함한 어떤 정보도 수집하거나 전송하지 않습니다. 앱은 Apple 공증(notarization)을 거쳐 배포됩니다. 문제가 있다면 앱 안의 Help ▸ Report a Bug 메뉴나 support@yjlab.io로 알려주세요.
