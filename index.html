Explorer for Mac

A native macOS file manager for people who know Windows Explorer by heart — browse and manage files with the structure your hands already know.

  • Persistent folder tree, tabs, and Favorites — the navigation Windows users expect
  • Cut, copy, paste, and ⌘R rename — your Windows shortcuts just work
  • Undo and Redo for moves, renames, deletes, and copies — ⌘Z / ⌘⇧Z
  • Folder sizes right in the Details view — visible at a glance, sortable like any column
  • File-safety-first design, fully offline, zero telemetry

macOS · MCP server

Terminal MCP

A local MCP server that lets Claude and other AI agents drive Apple's Terminal.app — while you keep per-session control over what they can touch.

  • Real Terminal windows and scrollback — no hidden shells
  • Per-session permissions: block, read-only, or allow commands
  • One-click pause stops all changes from the menu bar
  • 100% local — no HTTP server, no cloud, zero telemetry
