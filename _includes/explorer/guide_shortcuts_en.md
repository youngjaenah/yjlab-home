# Keyboard Shortcuts

Explorer for Mac keeps the Windows Explorer shortcuts you already know, with **⌘ (Command)** in place of **Ctrl**. The tables below list every shortcut in the app alongside its closest Windows 11 File Explorer equivalent. "—" means Windows has no direct equivalent.

Symbols: **⌘** Command · **⇧** Shift · **⌥** Option · **⌃** Control · **↩** Return · **⌫** Delete (Backspace) · **⌦** Forward Delete (fn + Delete) · **⇥** Tab · **↑ ↓** arrow keys

Shortcuts marked **(Pro)** require [Explorer Pro](/explorer/guide/pro/?lang=en).

## Navigation

| Action | Explorer for Mac | Windows Explorer equivalent |
|---|---|---|
| Open the selected folder or file | ↩ or ⌘O | Enter |
| Go up to the parent folder (**Go ▸ Enclosing Folder**) | ⌘↑ | Alt+↑ |
| Go up to the parent folder | ⌫ | Alt+↑ (Backspace means Back in Windows) |
| Back | ⌘[ | Alt+← |
| Forward | ⌘] | Alt+→ |
| Type a path in the address bar (**Go ▸ Edit Path**) | ⌘L | Ctrl+L or Alt+D |
| Address bar: go to the typed path | ↩ | Enter |
| Address bar: open or move through suggestions | ↓ / ↑ | ↓ / ↑ |
| Address bar: stop editing | Esc | Esc |
| Jump to an item by name | Type the first letters | Type the first letters |

## Windows keys that work differently here

- **F2 (rename)**: use **⌘R**. Mac keyboards use F2 for screen brightness, so the app never receives it.
- **Backspace**: goes up to the parent folder and never deletes. To go back, use **⌘[**.
- **Delete**: use **⌘⌫**, or **⌦** (fn + Delete on laptops).
- **F5 (refresh)**: not needed, because folders update automatically. **Refresh** is in the right-click menu.
