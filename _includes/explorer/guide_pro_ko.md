# Explorer Pro 기능 사용법

이 문서는 Explorer Pro에 포함된 기능을 하나씩 사용하는 방법을 설명합니다. Pro를 아직 활성화하지 않았다면 먼저 [라이선스 가이드](/explorer/guide/license/)를 따라 라이선스를 등록해 주세요. 앱 화면은 영어로만 제공되므로, 이 문서에서도 메뉴와 버튼 이름은 앱에 표시되는 영어 그대로 적었습니다.

## Pro 기능이 표시되는 방식

- 라이선스가 없으면 메뉴 막대의 Pro 항목 옆에 **PRO** 배지가 붙습니다. 선택하면 **Upgrade to Pro…**, **Import License…**, **Cancel** 버튼이 있는 안내 창만 열리고, 그 외의 동작은 일어나지 않습니다.
- 마우스 오른쪽 버튼 메뉴(컨텍스트 메뉴)에서는 Pro 항목이 배지 없이 아예 숨겨집니다. 라이선스를 등록하면 다음에 메뉴를 열 때부터 바로 나타납니다.
- 라이선스는 앱을 다시 시작하지 않아도 즉시 적용됩니다.
- 무료 기능은 Pro 여부와 관계없이 그대로 동작합니다. 무료 기능의 사용법은 [자주 묻는 질문](/explorer/guide/faq/)과 [키보드 단축키](/explorer/guide/shortcuts/)를 참고하세요.

## 듀얼 페인 보기 (Dual-Pane View)

한 탭 안에서 폴더 두 개를 좌우로 나란히 열고, 한쪽에서 다른 쪽으로 파일을 복사하거나 이동합니다.

**여는 방법**: **View ▸ Dual-Pane View** (⌘\\) 또는 도구 막대 오른쪽의 **Dual-Pane View** 버튼

1. 기준이 될 폴더로 이동한 뒤 **View ▸ Dual-Pane View**를 선택합니다. 원래 화면은 왼쪽 페인에 그대로 남고 오른쪽에 새 페인이 열립니다.
2. 오른쪽 페인을 클릭해 활성화하고 대상 폴더로 이동합니다. 주소 표시줄, 사이드바, 상태 표시줄, 미리보기는 항상 활성 페인을 따라갑니다.
3. 한쪽 페인에서 파일을 선택하고 **Edit ▸ Copy to Other Pane** (⇧⌥⌘C) 또는 **Edit ▸ Move to Other Pane** (⇧⌥⌘M)을 선택합니다. 같은 항목은 파일을 오른쪽 클릭했을 때도 나타납니다.
4. 파일을 다른 페인으로 끌어다 놓아도 됩니다. 같은 볼륨이면 이동, 다른 볼륨이면 복사되며, Option 키를 누른 채 끌면 복사합니다.
5. 다시 **View ▸ Dual-Pane View**를 선택하면 한 페인으로 돌아갑니다. 이때 활성 페인의 위치와 선택 상태가 유지됩니다.

- 두 페인은 위치, 정렬, 보기 방식이 서로 독립적입니다.
- 다른 페인으로 복사/이동할 때도 일반 복사와 똑같이 진행률 창, 이름 충돌 확인, 실행 취소(⌘Z 한 번으로 전체 취소)가 적용됩니다.
- 분할 상태는 탭별로 저장되어 앱을 다시 시작해도 그대로 복원됩니다.
- 한 페인으로 되돌리는 동작은 라이선스가 없어도 언제나 가능합니다.

## 일괄 이름 바꾸기 (Batch Rename)

여러 파일의 이름을 찾아 바꾸기, 정규식, 일련번호, 대소문자 변환으로 한 번에 바꿉니다.

**여는 방법**: 파일을 선택한 뒤 **Edit ▸ Batch Rename…** 또는 오른쪽 클릭 ▸ **Batch Rename…** (단축키 없음)

1. 이름을 바꿀 파일을 선택하고 **Batch Rename…**을 엽니다. 파일 하나만 선택해도 사용할 수 있습니다.
2. **Find:**와 **Replace:**에 바꿀 문자열을 입력합니다. 필요하면 **Case sensitive**, **Include extension**(확장자까지 대상에 포함), **Use regular expressions**를 켭니다. 정규식에서는 `$1`, `$2`처럼 캡처 그룹을 쓸 수 있습니다.
3. 번호를 붙이려면 **Add sequence numbers**를 켜고 **Start:**, **Increment:**, **Padding:**(자릿수), **Separator:**를 정하고, 번호를 앞(**Prefix**)에 붙일지 뒤(**Suffix**)에 붙일지 고릅니다. 번호는 목록에 보이는 순서대로 붙습니다.
4. **Case:**에서 **None**, **lowercase**, **UPPERCASE**, **Title Case** 중 하나를 고릅니다. 확장자의 대소문자는 바뀌지 않습니다.
5. 아래 표의 **Current**와 **Proposed** 열에서 결과를 확인하고 **Rename**을 누릅니다.

- 미리보기는 입력하는 즉시 갱신되며, **Rename**을 누르기 전에는 디스크에 아무것도 바뀌지 않습니다.
- 이름이 겹치거나 사용할 수 없는 이름(`/` 포함 등)이 있으면 해당 행이 표시되고 **Rename** 버튼이 비활성화됩니다. 잘못된 정규식도 같은 방식으로 막힙니다.
- 일부 파일이 실패해도 나머지는 정상적으로 바뀌고, 실패한 항목과 이유가 결과에 표시됩니다.
- **Edit ▸ Undo Batch Rename** (⌘Z) 한 번으로 이번 작업 전체가 원래 이름으로 돌아갑니다. 휴지통 안에서는 사용할 수 없습니다.

## 폴더 비교 및 동기화 (Compare Folders)

두 폴더의 차이를 분류해서 보여 주고, 선택한 항목만 한쪽 방향 또는 양방향으로 맞춥니다.

**여는 방법**: **Tools ▸ Compare Folders…**

1. **Compare Folders…**를 엽니다. 듀얼 페인 상태라면 두 페인의 폴더가 **Left:**, **Right:**에 미리 채워지고, 아니면 활성 폴더가 채워집니다. 다른 폴더는 **Choose…**로 고릅니다.
2. **Compare**를 누릅니다. 비교는 **Quick compare (size + date)**, 즉 크기와 수정 날짜를 기준으로 하며 진행 중에 **Cancel**할 수 있습니다.
3. 결과가 **Only in Left**, **Only in Right**, **Newer in Left**, **Newer in Right**, **Identical**로 나뉘어 표시됩니다. 이 단계까지는 어느 폴더에도 아무것도 쓰지 않습니다.
4. **Direction:**에서 **Left → Right**, **Right → Left**, **Both (newest wins)** 중 하나를 고르고, 각 항목이나 분류 옆 체크박스로 동기화할 대상을 고릅니다.
5. 위쪽의 요약(복사·교체·휴지통 이동 개수와 전송량)을 확인한 뒤 **Run**을 누릅니다.

- 대상 쪽에만 있는 파일의 삭제는 기본적으로 꺼져 있으며, 직접 체크해야만 실행됩니다.
- 교체되는 파일과 삭제되는 파일은 영구 삭제되지 않고 휴지통으로 이동합니다.
- **Both (newest wins)**는 각 파일의 더 최신 쪽을 반대편으로 복사하며, 삭제는 하지 않습니다. **Identical** 항목은 동기화되지 않습니다.
- 중간에 취소해도 반쯤 쓰인 파일이 최종 이름으로 남지 않습니다. 읽을 수 없는 하위 폴더는 비교에서 제외되었다고 표시됩니다.

## 디스크 사용량 분석 (Analyze Disk Usage)

폴더나 볼륨 안에서 어떤 하위 폴더와 파일이 공간을 많이 차지하는지 크기 순으로 보여 줍니다.

**여는 방법**: **Tools ▸ Analyze Disk Usage…**(현재 폴더), 폴더를 오른쪽 클릭 ▸ **Analyze Disk Usage…**, 또는 사이드바의 폴더·볼륨을 오른쪽 클릭 ▸ **Analyze Disk Usage…**

1. 분석할 폴더에서 **Analyze Disk Usage…**를 엽니다. **Disk Space Analyzer** 창에 큰 항목부터 결과가 차례로 채워집니다.
2. 각 행에는 크기와 상위 폴더 대비 비율(**Share**)이 표시됩니다. 폴더 행을 더블클릭하면 그 안으로 들어가고, 위쪽 경로 표시를 클릭하면 상위로 돌아갑니다.
3. 아래 **Largest Files** 목록에서 가장 큰 파일들을 확인합니다.
4. 행을 오른쪽 클릭해 **Move to Trash**, **Reveal in Explorer**(메인 창에서 해당 위치 열기), **Get Info**를 실행합니다.

- 휴지통으로 보낸 파일은 메인 창에서 ⌘Z로 되돌릴 수 있으며, 분석 결과의 합계도 바로 갱신됩니다.
- 항목이 아주 많은 폴더는 작은 항목들이 **Other (N items)** 한 줄로 묶이며, 더블클릭하면 펼쳐집니다.
- 일부를 읽을 수 없는 폴더는 크기 앞에 **≥**가 붙어 "최소 이 크기"임을 나타냅니다. 앱(.app) 같은 패키지는 내부로 들어가지 않고 하나의 항목으로 표시됩니다.
- 스캔은 **Cancel** 버튼이나 Esc로 언제든 멈출 수 있고, 그때까지의 결과는 계속 볼 수 있습니다. 볼륨을 분석하면 사용 공간·여유 공간·전체 용량도 함께 표시됩니다.

## 중복 파일 찾기 (Find Duplicates)

내용이 완전히 같은 파일을 찾아 그룹으로 묶고, 남길 사본을 정한 뒤 나머지를 휴지통으로 보냅니다.

**여는 방법**: **Tools ▸ Find Duplicates…**(현재 폴더), 폴더를 오른쪽 클릭 ▸ **Find Duplicates…**, 또는 사이드바의 폴더·볼륨을 오른쪽 클릭 ▸ **Find Duplicates…**

1. 검사할 폴더에서 **Find Duplicates…**를 엽니다. 하위 폴더까지 스캔하며, 진행 중에 **Cancel**할 수 있습니다.
2. 결과는 낭비되는 공간이 큰 그룹부터 표시됩니다. 처음에는 어떤 파일도 삭제 대상으로 체크되어 있지 않습니다.
3. 지울 사본의 체크박스를 직접 켜거나, **Keep in each group:** 옆의 **Oldest**, **Newest**, **In Folder…** 버튼으로 그룹마다 남길 파일을 한 번에 정합니다.
4. 아래 요약(그룹 수, 체크한 파일 수, 확보되는 용량)을 확인하고 **Move Duplicates to Trash**를 누른 뒤 확인 창에서 승인합니다.

- 크기와 내용을 모두 비교하므로, 크기만 같은 다른 파일은 중복으로 묶이지 않습니다. 0바이트 파일, 하드 링크, 심볼릭 링크도 제외됩니다.
- 그룹마다 최소 한 개의 사본은 반드시 남으며, 마지막 사본은 체크할 수 없습니다.
- 파일은 휴지통으로 이동하며, 메인 창에서 ⌘Z로 원래 위치에 되돌릴 수 있습니다.
- 스캔 후 내용이 바뀌거나 사라진 파일은 삭제 직전에 다시 확인해 건너뛰고, 그 사실을 알려 줍니다.

## 하위 폴더 전체 검색 (Find in All Subfolders)

현재 폴더 아래의 모든 하위 폴더에서 파일 이름이나 파일 내용을 검색합니다.

**여는 방법**: **Edit ▸ Find in All Subfolders…** (⇧⌘F), 또는 검색창 옆 범위 메뉴에서 **All Subfolders** 선택

1. 검색을 시작할 폴더로 이동한 뒤 ⇧⌘F를 누릅니다. 검색창이 **All Subfolders** 범위로 바뀌고 안내 문구가 "Search subfolders — press Return"으로 표시됩니다.
2. 검색창 옆 메뉴에서 **Name**(파일 이름) 또는 **Contents**(텍스트 파일 내용)를 고릅니다.
3. 검색어를 입력하고 Return을 누릅니다. 결과가 찾는 대로 목록에 계속 추가되며, **Location** 열에 각 파일이 있는 하위 폴더가 표시됩니다.
4. 결과를 더블클릭하면 파일이 열리고, 오른쪽 클릭 ▸ **Open Containing Folder**를 선택하면 그 파일이 있는 폴더로 이동해 파일을 선택해 줍니다.
5. Esc를 누르거나 범위를 **This Folder**로 바꾸면 원래 폴더 목록으로 돌아갑니다.

- 이름 검색은 무료 검색과 같은 규칙을 따르므로 `*.pdf` 같은 와일드카드도 사용할 수 있습니다.
- macOS Spotlight 색인을 먼저 사용하고, 색인되지 않은 위치(네트워크 공유 등)는 자동으로 폴더를 직접 탐색합니다. 앱이 자체 색인을 만들거나 백그라운드 작업을 남기지 않습니다.
- 결과 목록에서도 정렬, 미리보기, 필터 막대를 그대로 사용할 수 있습니다.
- 현재 폴더만 좁혀 보는 기존 검색(**Edit ▸ Find**, ⌘F, 범위 **This Folder**)은 무료 기능으로 그대로 유지됩니다.

## 저장된 검색 (Saved Searches)

자주 쓰는 하위 폴더 검색을 이름을 붙여 사이드바에 저장하고, 클릭 한 번으로 다시 실행합니다.

**여는 방법**: 하위 폴더 검색 결과가 표시된 상태에서 **Edit ▸ Save Search…**

1. 위의 방법으로 하위 폴더 검색을 실행하고, 필요하면 필터 막대로 종류·날짜·크기를 좁힙니다.
2. **Edit ▸ Save Search…**를 선택하고 이름을 입력한 뒤 **Save**를 누릅니다.
3. 사이드바의 **Saved Searches** 그룹에 항목이 추가됩니다. 나중에 클릭하면 저장한 폴더로 이동해 같은 검색어, 같은 검색 방식(Name/Contents), 같은 필터로 검색을 다시 실행합니다.
4. 항목을 오른쪽 클릭하면 **Rename…** 또는 **Delete Saved Search**를 선택할 수 있습니다.

- **Save Search…**는 하위 폴더 검색이 진행 중이거나 결과가 표시되어 있을 때만 활성화됩니다.
- "Last 7 days" 같은 날짜 필터는 실행하는 시점을 기준으로 다시 계산됩니다.
- 저장한 폴더가 없거나 볼륨이 연결되어 있지 않으면 **Folder Not Available** 안내만 표시되고 검색은 실행되지 않습니다.
- 저장된 검색은 이 Mac에만 저장되며, 삭제해도 실제 파일에는 아무 영향이 없습니다.

## 필터 막대 (View Filters)

현재 폴더 목록을 파일 종류, 수정 날짜, 크기로 걸러 봅니다. 검색창의 이름 검색과 함께 조합됩니다.

**여는 방법**: Pro가 활성화되면 주소 표시줄 바로 아래, 파일 목록 위에 필터 막대가 항상 표시됩니다.

1. 종류 버튼(**Folders**, **Images**, **Docs**, **Audio**, **Video**, **Archives**) 중 하나 이상을 누릅니다. 여러 개를 고르면 그중 하나에 해당하는 항목이 모두 표시됩니다.
2. 날짜 메뉴에서 **Any date**, **Today**, **Last 7 days**, **Last 30 days**, **This year** 중 하나를 고릅니다.
3. 크기 메뉴에서 **Any size**, **Smaller than 1 MB**, **1 MB – 100 MB**, **Larger than 100 MB**, **Larger than 1 GB** 중 하나를 고릅니다.
4. 막대 오른쪽의 **Showing X of Y**로 걸러진 개수를 확인합니다. **Clear**를 누르면 이름 검색까지 포함한 모든 조건이 해제됩니다.

- 모든 조건은 AND로 결합됩니다. 예: 이름에 "Invoice" + **Docs** + **This year**.
- 필터는 항목을 숨기기만 할 뿐 파일을 옮기거나 바꾸지 않습니다.
- 다른 폴더로 이동하거나 탭·페인을 바꾸면 필터가 초기화됩니다.
- 크기 필터를 쓰는 동안 크기가 아직 계산되지 않은 폴더는 결과에서 제외됩니다.

## 그룹으로 보기 (Group by)

Windows 탐색기처럼 자세히(Details) 보기의 목록을 날짜, 종류, 크기, 이름별 그룹으로 나눠 보여 줍니다.

**여는 방법**: **View ▸ Group by**, 파일 목록의 빈 곳을 오른쪽 클릭 ▸ **Group by**, 또는 열 머리글을 오른쪽 클릭 ▸ **Group by**

1. 폴더를 **Details** 보기로 엽니다. 그룹은 Details 보기에서만 적용됩니다.
2. **Group by**에서 **Name**, **Date Modified**, **Type**, **Size** 중 하나를 고릅니다.
3. 목록이 그룹 머리글과 항목 수(예: "Today (12)")로 나뉩니다. 날짜는 **Today**, **Yesterday**, **Earlier this week**, **Last week**, **Earlier this month**, **Last month**, **Earlier this year**, **A long time ago** 순으로 묶입니다.
4. 그룹 머리글을 클릭하면 그 그룹을 접거나 펼칩니다.
5. 그룹을 끄려면 **Group by ▸ (None)**을 선택합니다.

- 이름 그룹은 **0 - 9**, **A - H**, **I - P**, **Q - Z**, **ㄱ - ㅎ**, **Other**로, 크기 그룹은 **Empty (0 KB)**부터 **Gigantic (>4 GB)**까지 Windows와 같은 구간으로 나뉩니다. 크기를 모르는 폴더는 **Unknown**에 들어갑니다.
- 열 머리글을 클릭해 정렬하면 그룹 순서는 유지된 채 각 그룹 안에서 정렬됩니다.
- 이름 검색과 필터 막대가 먼저 적용되며, 머리글의 개수도 걸러진 결과 기준입니다.
- 그룹 기준은 페인마다 따로 적용되고, 마지막으로 고른 기준이 새 페인과 다음 실행의 기본값이 됩니다. 검색 결과와 ZIP 내부에서는 그룹을 사용할 수 없습니다.

## ZIP 파일 바로 열어 보기 (Browse Archive)

.zip 파일을 압축 해제하지 않고 폴더처럼 열어 내용을 보고, 미리보고, 필요한 파일만 꺼냅니다.

**여는 방법**: .zip 파일을 더블클릭, 또는 오른쪽 클릭 ▸ **Browse Archive**

1. .zip 파일을 더블클릭하면 폴더처럼 열립니다. 주소 표시줄에 `…/파일이름.zip`이 표시됩니다.
2. 하위 폴더로 들어가고, 뒤로 가기·위로 가기로 빠져나옵니다. ZIP의 최상위에서 위로 가면 ZIP이 있던 폴더로 돌아갑니다.
3. 파일을 선택하면 미리보기 창에 내용이 표시되고, 더블클릭하면 기본 앱에서 읽기 전용 사본으로 열립니다.
4. 파일을 꺼내려면 선택 후 ⌘C를 누르고 일반 폴더로 이동해 ⌘V로 붙여 넣거나, 다른 페인이나 Finder로 끌어다 놓습니다.

- ZIP 내부는 읽기 전용입니다. 붙여넣기, 삭제, 이름 바꾸기, 새 폴더 만들기는 할 수 없으며 원본 ZIP 파일은 절대 변경되지 않습니다.
- ZIP을 예전처럼 기본 앱으로 열고 싶다면 오른쪽 클릭 ▸ **Open with Default App**을 선택합니다.
- 암호가 걸린 ZIP은 목록은 보이지만, 항목을 열거나 미리보거나 꺼내려고 하면 "Encrypted archives are not supported." 안내가 표시됩니다.
- Pro가 없으면 .zip 파일은 더블클릭할 때 이전과 같이 기본 앱으로 열립니다. 하위 폴더 검색은 ZIP 내부에서는 동작하지 않습니다.

## ZIP으로 압축 (Compress to ZIP)

선택한 파일과 폴더를 새 .zip 파일로 압축합니다. 필요하면 암호(AES-256)를 걸 수 있습니다.

**여는 방법**: 파일을 선택한 뒤 **File ▸ Compress to ZIP** / **File ▸ Compress with Password…**, 또는 오른쪽 클릭 ▸ 같은 이름의 항목

1. 압축할 파일과 폴더를 선택합니다.
2. **Compress to ZIP**을 선택하면 선택 항목 옆에 새 ZIP 파일이 만들어지고 선택됩니다. 항목이 하나면 그 이름으로, 여러 개면 들어 있는 폴더 이름으로 만들어집니다.
3. 암호를 걸려면 **Compress with Password…**를 선택하고, 같은 암호를 두 번 입력한 뒤 **Compress**를 누릅니다.

- 같은 이름의 ZIP이 이미 있으면 덮어쓰지 않고 "이름 2.zip"처럼 새 이름으로 만듭니다. 기존 ZIP에 파일을 추가하는 기능은 없습니다.
- 원본 파일은 바뀌지 않습니다. 큰 작업은 진행률 창에서 취소할 수 있으며, 취소하면 만들던 ZIP은 남지 않습니다.
- ⌘Z로 실행 취소하면 만든 ZIP 파일이 휴지통으로 이동합니다.
- 휴지통 안이나 ZIP 내부에서는 사용할 수 없습니다. 암호를 비워 두거나 두 입력이 다르면 창이 닫히지 않고 안내가 표시됩니다.

## 임시 보관함 (Stash Shelf)

여러 폴더에서 파일을 잠시 모아 두었다가, 목적지 폴더에서 한 번에 복사하거나 이동합니다.

**여는 방법**: **View ▸ Show Stash Shelf** (⇧⌘Y), 또는 파일을 오른쪽 클릭 ▸ **Add to Stash Shelf**

1. **View ▸ Show Stash Shelf**를 선택하면 파일 목록과 상태 표시줄 사이에 얇은 보관함 줄이 나타납니다.
2. 파일이나 폴더를 보관함으로 끌어다 놓거나, 오른쪽 클릭 ▸ **Add to Stash Shelf**를 선택합니다. 보관함이 숨겨져 있었다면 자동으로 나타납니다.
3. 목적지 폴더로 이동합니다.
4. 보관함의 항목을 오른쪽 클릭하고 **Copy All to Current Folder** 또는 **Move All to Current Folder**를 선택합니다. 항목 하나를 파일 목록이나 Finder로 끌어다 놓아도 복사됩니다.
5. 다 쓴 항목은 오른쪽 클릭 ▸ **Remove from Shelf**(한 항목) 또는 **Clear Shelf**(전체)로 비웁니다.

- 보관함은 파일의 위치만 기억할 뿐, 넣는 것만으로는 아무것도 복사·이동되지 않습니다. **Remove from Shelf**와 **Clear Shelf**도 실제 파일에는 영향이 없습니다.
- 복사/이동은 일반 작업과 같이 진행률, 이름 충돌 확인, 실행 취소를 지원합니다. 이동에 성공한 항목은 보관함에서 빠집니다.
- 보관함의 내용은 모든 창이 함께 쓰며 앱을 다시 시작해도 유지됩니다. 표시 여부는 창마다 따로 정합니다.
- 다른 곳에서 삭제되거나 옮겨진 파일은 흐리게 표시되고 작업에서 건너뜁니다. ZIP 내부의 항목은 넣을 수 없습니다.

## 이름 붙인 탭 세션 (Tab Sessions)

현재 창의 탭 구성을 이름을 붙여 저장해 두었다가, 나중에 새 창으로 다시 엽니다.

**여는 방법**: **Window ▸ Save Tab Session…**, **Window ▸ Tab Sessions**

1. 작업에 필요한 탭들을 열어 둡니다. 듀얼 페인 분할, 페인별 정렬과 보기 방식도 함께 저장됩니다.
2. **Window ▸ Save Tab Session…**을 선택하고 이름을 입력한 뒤 **Save**를 누릅니다.
3. 나중에 **Window ▸ Tab Sessions**에서 세션을 고르면 저장한 탭들이 새 창으로 열립니다. 목록에는 탭 개수와 저장 시각이 함께 표시됩니다.
4. 이름을 바꾸거나 지우려면 **Window ▸ Tab Sessions ▸ Manage Sessions…**를 엽니다. 행을 선택하고 Return을 누르면 이름을 바꿀 수 있고, **Delete**로 삭제합니다.

- 세션은 항상 새 창으로 열리므로, 지금 열려 있는 창과 탭은 바뀌지 않습니다.
- 저장 후 사라진 폴더의 탭은 건너뛰고, 모든 폴더가 없으면 Home 탭 하나로 열립니다.
- 같은 이름으로 여러 번 저장할 수 있으며, 삭제는 확인 후 실행되고 되돌릴 수 없습니다.
- 앱을 다시 시작할 때 마지막 탭을 자동으로 복원하는 기능은 이와 별개인 무료 기능입니다.

## 라이선스가 해제되면

환불 등으로 라이선스를 제거해도 저장된 검색, 탭 세션, 보관함 목록 같은 데이터는 지워지지 않고 이 Mac에 남아 있으며, 다시 라이선스를 등록하면 그대로 사용할 수 있습니다. 무료 기능은 계속 정상적으로 동작합니다. 궁금한 점은 [자주 묻는 질문](/explorer/guide/faq/)을 확인하거나 support@yjlab.io로 문의해 주세요.
