# Explorer Pro 기능 사용법

이 문서는 Explorer Pro에 포함된 기능을 하나씩 사용하는 방법을 설명합니다. Pro를 아직 활성화하지 않았다면 먼저 [라이선스 가이드](/explorer/guide/license/)를 따라 라이선스를 등록해 주세요. Mac 언어가 한국어면 메뉴와 버튼이 한국어로 표시되고, 영어로 설정한 경우에는 영어로 표시됩니다.

## Pro 기능이 표시되는 방식

- 라이선스가 없으면 메뉴 막대의 Pro 항목 옆에 **PRO** 배지가 붙습니다. 선택하면 **Pro로 업그레이드…**, **라이선스 가져오기…**, **취소** 버튼이 있는 안내 창만 열리고, 그 외의 동작은 일어나지 않습니다.
- 마우스 오른쪽 버튼 메뉴(컨텍스트 메뉴)에서는 Pro 항목이 배지 없이 아예 숨겨집니다. 라이선스를 등록하면 다음에 메뉴를 열 때부터 바로 나타납니다.
- 라이선스는 앱을 다시 시작하지 않아도 즉시 적용됩니다.
- 무료 기능은 Pro 여부와 관계없이 그대로 동작합니다. 무료 기능의 사용법은 [자주 묻는 질문](/explorer/guide/faq/)과 [키보드 단축키](/explorer/guide/shortcuts/)를 참고하세요.

## 듀얼 창 보기 (Dual-Pane View)

한 탭 안에서 폴더 두 개를 좌우로 나란히 열고, 한쪽에서 다른 쪽으로 파일을 복사하거나 이동합니다.

**여는 방법**: **보기 ▸ 듀얼 창 보기** (⌘\\) 또는 도구 막대 오른쪽의 **듀얼 창 보기** 버튼(버튼은 Pro를 활성화하면 나타납니다)

1. 기준이 될 폴더로 이동한 뒤 **보기 ▸ 듀얼 창 보기**를 선택합니다. 원래 화면은 왼쪽 창에 그대로 남고 오른쪽에 새 창이 열립니다.
2. 오른쪽 창을 클릭해 활성화하고 대상 폴더로 이동합니다. 주소 표시줄, 사이드바, 상태 표시줄, 미리보기는 항상 활성 창을 따라갑니다.
3. 한쪽 창에서 파일을 선택하고 **편집 ▸ 반대쪽 창으로 복사** (⇧⌥⌘C) 또는 **편집 ▸ 반대쪽 창으로 이동** (⇧⌥⌘M)을 선택합니다. 같은 항목은 파일을 오른쪽 클릭했을 때도 나타납니다.
4. 파일을 다른 창으로 끌어다 놓아도 됩니다. 같은 볼륨이면 이동, 다른 볼륨이면 복사되며, Option 키를 누른 채 끌면 복사합니다.
5. 다시 **보기 ▸ 듀얼 창 보기**를 선택하면 한 창으로 돌아갑니다. 이때 활성 창의 위치와 선택 상태가 유지됩니다.

- 두 창은 위치, 정렬, 보기 방식이 서로 독립적입니다.
- 다른 창으로 복사/이동할 때도 일반 복사와 똑같이 진행률 창, 이름 충돌 확인, 실행 취소(⌘Z 한 번으로 전체 취소)가 적용됩니다.
- 분할 상태는 탭별로 저장되어 앱을 다시 시작해도 그대로 복원됩니다.
- 한 창으로 되돌리는 동작은 라이선스가 없어도 언제나 가능합니다.

## 일괄 이름 바꾸기 (Batch Rename)

여러 파일의 이름을 찾아 바꾸기, 정규식, 일련번호, 대소문자 변환으로 한 번에 바꿉니다.

**여는 방법**: 파일을 선택한 뒤 **편집 ▸ 일괄 이름 바꾸기…** 또는 오른쪽 클릭 ▸ **일괄 이름 바꾸기…** (단축키 없음)

1. 이름을 바꿀 파일을 선택하고 **일괄 이름 바꾸기…**를 엽니다. 파일 하나만 선택해도 사용할 수 있습니다.
2. **찾을 내용:**과 **바꿀 내용:**에 바꿀 문자열을 입력합니다. 필요하면 **대/소문자 구분**, **확장명 포함**(확장자까지 대상에 포함), **정규 표현식 사용**을 켭니다. 정규식에서는 `$1`, `$2`처럼 캡처 그룹을 쓸 수 있습니다.
3. 번호를 붙이려면 **일련번호 추가**를 켜고 **시작:**, **증가값:**, **자릿수:**, **구분 기호:**를 정하고, 번호를 앞에 붙일지(**앞에 붙이기**) 뒤에 붙일지(**뒤에 붙이기**) 고릅니다. 번호는 목록에 보이는 순서대로 붙습니다.
4. **대/소문자:**에서 **없음**, **소문자**, **대문자**, **단어 첫 글자 대문자** 중 하나를 고릅니다. 확장자의 대소문자는 바뀌지 않습니다.
5. 아래 표의 **현재 이름**과 **새 이름** 열에서 결과를 확인하고 **이름 바꾸기**를 누릅니다.

- 미리보기는 입력하는 즉시 갱신되며, **이름 바꾸기**를 누르기 전에는 디스크에 아무것도 바뀌지 않습니다.
- 이름이 겹치거나 사용할 수 없는 이름(`/` 포함 등)이 있으면 해당 행이 표시되고 **이름 바꾸기** 버튼이 비활성화됩니다. 잘못된 정규식도 같은 방식으로 막힙니다.
- 일부 파일이 실패해도 나머지는 정상적으로 바뀌고, 실패한 항목과 이유가 결과에 표시됩니다.
- **편집 ▸ 일괄 이름 바꾸기 실행 취소** (⌘Z) 한 번으로 이번 작업 전체가 원래 이름으로 돌아갑니다. 휴지통 안에서는 사용할 수 없습니다.

## 폴더 비교 및 동기화 (Compare Folders)

두 폴더의 차이를 분류해서 보여 주고, 선택한 항목만 한쪽 방향 또는 양방향으로 맞춥니다.

**여는 방법**: **도구 ▸ 폴더 비교…**

1. **폴더 비교…**를 엽니다. 듀얼 창 상태라면 두 창의 폴더가 **왼쪽:**, **오른쪽:**에 미리 채워지고, 아니면 활성 폴더가 채워집니다. 다른 폴더는 **선택…**으로 고릅니다.
2. **비교**를 누릅니다. 비교는 **빠른 비교(크기 + 날짜)**, 즉 크기와 수정 날짜를 기준으로 하며 진행 중에 **취소**할 수 있습니다.
3. 결과가 **왼쪽에만 있음**, **오른쪽에만 있음**, **왼쪽이 최신**, **오른쪽이 최신**, **파일 vs. 폴더**, **동일함**으로 나뉘어 표시됩니다. 이 단계까지는 어느 폴더에도 아무것도 쓰지 않습니다.
4. **방향:**에서 **왼쪽 → 오른쪽**, **오른쪽 → 왼쪽**, **양방향(최신 파일 우선)** 중 하나를 고르고, 각 항목이나 분류 옆 체크박스로 동기화할 대상을 고릅니다.
5. 위쪽의 요약(복사·교체·휴지통 이동 개수와 전송량)을 확인한 뒤 **실행**을 누릅니다.

- 대상 쪽에만 있는 파일의 삭제는 기본적으로 꺼져 있으며, 직접 체크해야만 실행됩니다.
- 교체되는 파일과 삭제되는 파일은 영구 삭제되지 않고 휴지통으로 이동합니다.
- **양방향(최신 파일 우선)**은 각 파일의 더 최신 쪽을 반대편으로 복사하며, 삭제는 하지 않습니다. **동일함** 항목은 동기화되지 않습니다.
- **파일 vs. 폴더**는 같은 이름이 한쪽에는 파일, 다른 쪽에는 폴더로 있는 경우입니다. 어느 방향으로도 동기화되지 않으니, 한쪽의 이름을 바꾸거나 옮긴 뒤 다시 비교하세요.
- 중간에 취소해도 반쯤 쓰인 파일이 최종 이름으로 남지 않습니다. 읽을 수 없는 하위 폴더는 비교에서 제외되었다고 표시됩니다.

## 디스크 사용량 분석 (Analyze Disk Usage)

폴더나 볼륨 안에서 어떤 하위 폴더와 파일이 공간을 많이 차지하는지 크기 순으로 보여 줍니다.

**여는 방법**: **도구 ▸ 디스크 사용량 분석…**(현재 폴더), 폴더를 오른쪽 클릭 ▸ **디스크 사용량 분석…**, 또는 사이드바의 폴더·볼륨을 오른쪽 클릭 ▸ **디스크 사용량 분석…**

1. 분석할 폴더에서 **디스크 사용량 분석…**을 엽니다. **디스크 공간 분석기** 창에 큰 항목부터 결과가 차례로 채워집니다.
2. 각 행에는 크기와 상위 폴더 대비 비율(**비율** 열)이 표시됩니다. 폴더 행을 더블클릭하면 그 안으로 들어가고, 위쪽 경로 표시를 클릭하면 상위로 돌아갑니다.
3. 아래 **가장 큰 파일** 목록에서 가장 큰 파일들을 확인합니다.
4. 행을 오른쪽 클릭해 **휴지통으로 이동**, **Explorer에서 보기**(메인 창에서 해당 위치 열기), **정보 가져오기**를 실행합니다.

- 휴지통으로 보낸 파일은 메인 창에서 ⌘Z로 되돌릴 수 있으며, 분석 결과의 합계도 바로 갱신됩니다.
- 항목이 아주 많은 폴더는 작은 항목들이 **기타(항목 N개)** 한 줄로 묶이며, 더블클릭하면 펼쳐집니다.
- 일부를 읽을 수 없는 폴더는 크기 앞에 **≥**가 붙어 "최소 이 크기"임을 나타냅니다. 앱(.app) 같은 패키지는 내부로 들어가지 않고 하나의 항목으로 표시됩니다.
- 스캔은 **취소** 버튼이나 Esc로 언제든 멈출 수 있고, 그때까지의 결과는 계속 볼 수 있습니다. 볼륨을 분석하면 사용 공간·여유 공간·전체 용량도 함께 표시됩니다.

## 중복 파일 찾기 (Find Duplicates)

내용이 완전히 같은 파일을 찾아 그룹으로 묶고, 남길 사본을 정한 뒤 나머지를 휴지통으로 보냅니다.

**여는 방법**: **도구 ▸ 중복 파일 찾기…**(현재 폴더), 폴더를 오른쪽 클릭 ▸ **중복 파일 찾기…**, 또는 사이드바의 폴더·볼륨을 오른쪽 클릭 ▸ **중복 파일 찾기…**

1. 검사할 폴더에서 **중복 파일 찾기…**를 엽니다. 하위 폴더까지 스캔하며, 진행 중에 **취소**할 수 있습니다.
2. 결과는 낭비되는 공간이 큰 그룹부터 표시됩니다. 처음에는 어떤 파일도 삭제 대상으로 체크되어 있지 않습니다.
3. 지울 사본의 체크박스를 직접 켜거나, **각 그룹에서 유지할 항목:** 옆의 **오래된 항목**, **최신 항목**, **폴더 지정…** 버튼으로 그룹마다 남길 파일을 한 번에 정합니다.
4. 아래 요약(그룹 수, 체크한 파일 수, 확보되는 용량)을 확인하고 **중복 파일을 휴지통으로 이동**을 누른 뒤 확인 창에서 승인합니다.

- 크기와 내용을 모두 비교하므로, 크기만 같은 다른 파일은 중복으로 묶이지 않습니다. 0바이트 파일, 하드 링크, 심볼릭 링크도 제외됩니다.
- 숨김 파일·폴더(`.git` 등)와 개발 도구 폴더(`node_modules`, `DerivedData`, `Pods`, `__pycache__` 등)는 스캔하지 않습니다. 해당 앱이 그 위치에 파일이 있다고 전제하고 쓰기 때문에, 내용이 같아도 지우면 앱이 망가질 수 있습니다. 숨김 항목까지 검사하려면 창 아래쪽의 **숨김 파일 포함**을 켜세요. 처음부터 다시 스캔합니다. 개발 도구 폴더는 그 폴더 자체에서 중복 파일 찾기를 열 때만 검사됩니다.
- 그룹마다 최소 한 개의 사본은 반드시 남으며, 마지막 사본은 체크할 수 없습니다.
- 파일은 휴지통으로 이동하며, 메인 창에서 ⌘Z로 원래 위치에 되돌릴 수 있습니다.
- 스캔 후 내용이 바뀌거나 사라진 파일은 삭제 직전에 다시 확인해 건너뛰고, 그 사실을 알려 줍니다. 남길 사본도 함께 확인하며, 남길 사본이 바뀌었거나 사라졌으면 그 그룹에서는 아무것도 삭제하지 않습니다.

## 하위 폴더 전체 검색 (Find in All Subfolders)

현재 폴더 아래의 모든 하위 폴더에서 파일 이름이나 파일 내용을 검색합니다.

**여는 방법**: **편집 ▸ 모든 하위 폴더에서 찾기…** (⇧⌘F), 또는 검색창 옆 범위 메뉴에서 **모든 하위 폴더** 선택

1. 검색을 시작할 폴더로 이동한 뒤 ⇧⌘F를 누릅니다. 검색창이 **모든 하위 폴더** 범위로 바뀌고 안내 문구가 "하위 폴더 검색 — Return 키를 누르세요"로 표시됩니다.
2. 검색창 옆 메뉴에서 **이름**(파일 이름) 또는 **파일 내용**(텍스트 파일 내용)을 고릅니다.
3. 검색어를 입력하고 Return을 누릅니다. 결과가 찾는 대로 목록에 계속 추가되며, **위치** 열에 각 파일이 있는 하위 폴더가 표시됩니다.
4. 결과를 더블클릭하면 파일이 열리고, 오른쪽 클릭 ▸ **포함된 폴더 열기**를 선택하면 그 파일이 있는 폴더로 이동해 파일을 선택해 줍니다.
5. Esc를 누르거나 범위를 **현재 폴더**로 바꾸면 원래 폴더 목록으로 돌아갑니다.

- 이름 검색은 무료 검색과 같은 규칙을 따르므로 `*.pdf` 같은 와일드카드도 사용할 수 있습니다.
- macOS Spotlight 색인을 먼저 사용하고, 색인되지 않은 위치(네트워크 공유 등)는 자동으로 폴더를 직접 탐색합니다. 앱이 자체 색인을 만들거나 백그라운드 작업을 남기지 않습니다.
- 결과 목록에서도 정렬, 미리보기, 필터 막대를 그대로 사용할 수 있습니다.
- 현재 폴더만 좁혀 보는 기존 검색(**편집 ▸ 찾기**, ⌘F, 범위 **현재 폴더**)은 무료 기능으로 그대로 유지됩니다.

## 저장된 검색 (Saved Searches)

자주 쓰는 하위 폴더 검색을 이름을 붙여 사이드바에 저장하고, 클릭 한 번으로 다시 실행합니다.

**여는 방법**: 하위 폴더 검색 결과가 표시된 상태에서 **편집 ▸ 검색 저장…**

1. 위의 방법으로 하위 폴더 검색을 실행하고, 필요하면 필터 막대로 종류·날짜·크기를 좁힙니다.
2. **편집 ▸ 검색 저장…**을 선택하고 이름을 입력한 뒤 **저장**을 누릅니다.
3. 사이드바의 **저장된 검색** 그룹에 항목이 추가됩니다. 나중에 클릭하면 저장한 폴더로 이동해 같은 검색어, 같은 검색 방식(이름/파일 내용), 같은 필터로 검색을 다시 실행합니다.
4. 항목을 오른쪽 클릭하면 **이름 바꾸기…** 또는 **저장된 검색 삭제**를 선택할 수 있습니다.

- **검색 저장…**은 하위 폴더 검색이 진행 중이거나 결과가 표시되어 있을 때만 활성화됩니다.
- "지난 7일" 같은 날짜 필터는 실행하는 시점을 기준으로 다시 계산됩니다.
- 저장한 폴더가 없거나 볼륨이 연결되어 있지 않으면 **폴더를 사용할 수 없음** 안내만 표시되고 검색은 실행되지 않습니다.
- 저장된 검색은 이 Mac에만 저장되며, 삭제해도 실제 파일에는 아무 영향이 없습니다.

## 필터 막대 (View Filters)

현재 폴더 목록을 파일 종류, 수정 날짜, 크기로 걸러 봅니다. 검색창의 이름 검색과 함께 조합됩니다.

**여는 방법**: Pro가 활성화되면 주소 표시줄 바로 아래, 파일 목록 위에 필터 막대가 항상 표시됩니다.

1. 종류 버튼(**폴더**, **이미지**, **문서**, **오디오**, **비디오**, **압축 파일**) 중 하나 이상을 누릅니다. 여러 개를 고르면 그중 하나에 해당하는 항목이 모두 표시됩니다.
2. 날짜 메뉴에서 **모든 날짜**, **오늘**, **지난 7일**, **지난 30일**, **올해** 중 하나를 고릅니다.
3. 크기 메뉴에서 **모든 크기**, **1MB보다 작음**, **1MB – 100MB**, **100MB보다 큼**, **1GB보다 큼** 중 하나를 고릅니다.
4. 막대 오른쪽의 **Y개 중 X개 표시**로 걸러진 개수를 확인합니다. **초기화**를 누르면 이름 검색까지 포함한 모든 조건이 해제됩니다.

- 모든 조건은 AND로 결합됩니다. 예: 이름에 "Invoice" + **문서** + **올해**.
- 필터는 항목을 숨기기만 할 뿐 파일을 옮기거나 바꾸지 않습니다.
- 다른 폴더로 이동하거나 탭·창을 바꾸면 필터가 초기화됩니다.
- 크기 필터를 쓰는 동안 크기가 아직 계산되지 않은 폴더는 결과에서 제외됩니다.

## 그룹으로 보기 (Group by)

Windows 탐색기처럼 자세히 보기의 목록을 날짜, 종류, 크기, 이름별 그룹으로 나눠 보여 줍니다.

**여는 방법**: **보기 ▸ 그룹화 방법**, 파일 목록의 빈 곳을 오른쪽 클릭 ▸ **그룹화 방법**, 또는 열 머리글을 오른쪽 클릭 ▸ **그룹화 방법**

1. 폴더를 **자세히** 보기로 엽니다. 그룹은 자세히 보기에서만 적용됩니다.
2. **그룹화 방법**에서 **이름**, **수정한 날짜**, **유형**, **크기** 중 하나를 고릅니다.
3. 목록이 그룹 머리글과 항목 수(예: "오늘 (12)")로 나뉩니다. 날짜는 **오늘**, **어제**, **이번 주**, **지난주**, **이번 달**, **지난달**, **올해**, **오래전** 순으로 묶입니다.
4. 그룹 머리글을 클릭하면 그 그룹을 접거나 펼칩니다.
5. 그룹을 끄려면 **그룹화 방법 ▸ (없음)**을 선택합니다.

- 이름 그룹은 **0 - 9**, **A - H**, **I - P**, **Q - Z**, **ㄱ - ㅎ**, **기타**로, 크기 그룹은 **비어 있음(0KB)**부터 **거대함(4GB 초과)**까지 Windows와 같은 구간으로 나뉩니다. 크기를 모르는 폴더는 **알 수 없음**에 들어갑니다.
- 열 머리글을 클릭해 정렬하면 그룹 순서는 유지된 채 각 그룹 안에서 정렬됩니다.
- 이름 검색과 필터 막대가 먼저 적용되며, 머리글의 개수도 걸러진 결과 기준입니다.
- 그룹 기준은 창마다 따로 적용되고, 마지막으로 고른 기준이 새 창과 다음 실행의 기본값이 됩니다. 검색 결과와 압축 파일 내부에서는 그룹을 사용할 수 없습니다.

## 압축 파일 바로 열어 보기 (Browse Archive: ZIP, 7z, RAR, tar)

압축 파일을 풀지 않고 폴더처럼 열어 내용을 보고, 미리보고, 필요한 파일만 꺼냅니다. .zip, .7z, .rar, .tar, .tar.gz(.tgz), .tar.bz2, .tar.xz와 단일 .gz, .bz2, .xz 파일을 열 수 있습니다.

**여는 방법**: 압축 파일을 더블클릭, 또는 오른쪽 클릭 ▸ **압축 파일 열기**

1. 압축 파일을 더블클릭하면 폴더처럼 열립니다. 주소 표시줄에 `…/파일이름.zip`(또는 `…/파일이름.7z` 등)이 표시됩니다.
2. 하위 폴더로 들어가고, 뒤로 가기·위로 가기로 빠져나옵니다. 압축 파일의 최상위에서 위로 가면 압축 파일이 있던 폴더로 돌아갑니다.
3. 파일을 선택하면 미리보기 창에 표시됩니다. 더블클릭하면 읽기 전용 사본이 기본 앱으로 열립니다.
4. 파일을 꺼내려면 선택한 뒤 ⌘C를 누르고, 일반 폴더로 이동해 ⌘V를 누릅니다. 다른 창이나 Finder로 끌어다 놓아도 됩니다.

- 탐색만으로는 압축 파일이 바뀌지 않습니다. ZIP은 편집도 할 수 있습니다. 아래 **ZIP 편집**을 참고하세요. 7z, RAR, tar는 읽기 전용이며, 상태 표시줄에 "ZIP 압축 파일만 편집할 수 있으므로 이 압축 파일은 읽기 전용입니다."가 표시됩니다.
- .tar.gz, .tar.bz2, .tar.xz 파일에는 목차가 없어서, 큰 파일은 처음부터 끝까지 읽은 뒤에 목록이 나타납니다. 상태 표시줄에 "… 읽는 중… %"가 표시되며, Esc를 누르면 멈추고 원래 위치로 돌아갑니다.
- 같은 이름의 파일이나 폴더가 이미 있어 **바꾸기**를 고르면, 모든 항목을 꺼낸 뒤에만 바꿉니다. 꺼낼 수 없는 항목(예: 암호가 걸린 파일)이 있거나 취소하면 기존 파일이나 폴더는 그대로 남습니다.
- 압축 파일을 예전처럼 기본 앱으로 열고 싶다면 오른쪽 클릭 ▸ **기본 앱으로 열기**를 선택합니다.
- 암호가 걸린 압축 파일은 목록은 보이지만, 항목을 열거나 미리보거나 꺼내려고 하면 "이 압축 파일의 암호로 보호된 파일은 여기서 열 수 없습니다." 안내가 표시됩니다. 파일 이름까지 암호화된 7z·RAR과 분할 압축 파일(.7z.001, .part1.rar 등)은 열 수 없으며, 안내와 함께 **기본 앱으로 열기**를 제안합니다.
- tar 안의 링크는 목록에는 보이지만 꺼내지 않으며, 건너뛴 사실을 알려 줍니다.
- .tar.zst 등 다른 형식은 이전과 같이 기본 앱으로 열립니다.
- Pro가 없으면 압축 파일은 더블클릭할 때 이전과 같이 기본 앱으로 열립니다. 하위 폴더 검색은 압축 파일 내부에서는 동작하지 않습니다.

## ZIP 편집

탐색 중인 ZIP 안에서 일반 폴더처럼 파일을 추가하고, 삭제하고, 이름을 바꿉니다.

**여는 방법**: .zip을 **압축 파일 열기**로 연 뒤 파일을 끌어다 놓거나 붙여넣기, 또는 **새 폴더**, **이름 바꾸기**(⌘R), **삭제**

1. 파일을 추가하려면 ZIP의 파일 목록(또는 그 안의 폴더)에 끌어다 놓거나, 복사(⌘C)한 뒤 ZIP 안에서 붙여넣기(⌘V)합니다. **새 폴더**로 빈 폴더를 만들 수 있습니다. 파일을 옮겨 넣으려면 잘라내기(⌘X) 후 ZIP 안에서 붙여넣으세요. ZIP이 업데이트된 뒤 원본은 휴지통으로 이동하고, ⌘Z 한 번으로 모두 되돌릴 수 있습니다. ZIP으로 끌어다 놓으면 항상 복사됩니다.
2. 이름을 바꾸려면 항목을 선택하고 ⌘R을 누르거나 오른쪽 클릭 ▸ **이름 바꾸기**를 선택합니다. 폴더 이름을 바꾸면 그 안의 항목도 함께 바뀝니다.
3. 삭제하려면 항목을 선택하고 Delete 키를 누른 뒤 확인합니다.
4. 변경할 때마다 진행률 창이 표시됩니다. 취소할 수 있으며, 취소하면 ZIP은 그대로 남습니다.

- 변경할 때마다 새 ZIP을 완성한 뒤 원래 자리에 바꿔 넣습니다. 원래 ZIP은 휴지통으로 이동하므로 ⌘Z로 되돌릴 수 있습니다.
- 휴지통이 없는 드라이브(대부분의 네트워크 공유)에서는 이전 버전을 보관할 수 없고 되돌릴 수도 없으므로, 먼저 확인을 받습니다.
- 손대지 않은 파일은 암호가 걸린 파일을 포함해 원래 그대로 복사됩니다. 암호가 걸린 파일이 있는 ZIP에 파일을 추가하면 암호를 묻고, 새 파일도 그 암호로 보호합니다.
- 일부 ZIP은 탐색만 할 수 있습니다. 파일 이름이 유니코드가 아닌 옛 인코딩인 ZIP(예전 한국어·일본어 Windows에서 만든 ZIP에 흔함), 손상되었거나 분할된 ZIP, 자동 압축 해제(SFX) 파일이 그렇습니다. 상태 표시줄에 이유가 표시됩니다.
- 탐색하는 동안 다른 앱이 ZIP을 바꿨다면 변경은 거부되고 목록을 다시 불러옵니다.
- 추가하거나 이름을 바꾼 항목은 Windows가 쓰는 형식으로 저장되므로, 한글 이름도 Windows 파일 탐색기와 7-Zip에서 깨지지 않고 보입니다. Finder의 압축으로 만든 ZIP도 편집할 수 있습니다.

## ZIP으로 압축 (Compress to ZIP)

선택한 파일과 폴더를 새 .zip 파일로 압축합니다. 필요하면 암호(AES-256)를 걸 수 있습니다.

**여는 방법**: 파일을 선택한 뒤 **파일 ▸ ZIP 파일로 압축** / **파일 ▸ 암호를 설정하여 압축…**, 또는 오른쪽 클릭 ▸ 같은 이름의 항목

1. 압축할 파일과 폴더를 선택합니다.
2. **ZIP 파일로 압축**을 선택하면 선택 항목 옆에 새 ZIP 파일이 만들어지고 선택됩니다. 항목이 하나면 그 이름으로, 여러 개면 들어 있는 폴더 이름으로 만들어집니다.
3. 암호를 걸려면 **암호를 설정하여 압축…**을 선택하고, 같은 암호를 두 번 입력한 뒤 **압축**을 누릅니다.

- 같은 이름의 ZIP이 이미 있으면 덮어쓰지 않고 "이름 2.zip"처럼 새 이름으로 만듭니다. 기존 ZIP에 파일을 추가하려면 **ZIP 편집**을 참고하세요.
- 원본 파일은 바뀌지 않습니다. 큰 작업은 진행률 창에서 취소할 수 있으며, 취소하면 만들던 ZIP은 남지 않습니다.
- ⌘Z로 실행 취소하면 만든 ZIP 파일이 휴지통으로 이동합니다.
- 휴지통 안이나 압축 파일 내부에서는 사용할 수 없습니다. 암호를 비워 두거나 두 입력이 다르면 창이 닫히지 않고 안내가 표시됩니다.

## 임시 보관함 (Stash Shelf)

여러 폴더에서 파일을 잠시 모아 두었다가, 목적지 폴더에서 한 번에 복사하거나 이동합니다.

**여는 방법**: **보기 ▸ 임시 보관함 표시** (⇧⌘Y)

1. **보기 ▸ 임시 보관함 표시**를 선택하면 파일 목록과 상태 표시줄 사이에 얇은 보관함 줄이 나타나고 메뉴에 체크 표시가 붙습니다. 한 번 더 선택하면 숨겨집니다.
2. 파일이나 폴더를 보관함으로 끌어다 놓거나, 오른쪽 클릭 ▸ **임시 보관함에 추가**를 선택합니다. 이 메뉴는 보관함이 보이는 동안에만 나타납니다.
3. 목적지 폴더로 이동합니다.
4. 보관함의 항목을 오른쪽 클릭하고 **모두 현재 폴더로 복사** 또는 **모두 현재 폴더로 이동**을 선택합니다. 항목 하나를 파일 목록이나 Finder로 끌어다 놓아도 복사됩니다.
5. 다 쓴 항목은 오른쪽 클릭 ▸ **보관함에서 제거**(한 항목) 또는 **보관함 비우기**(전체)로 비웁니다.

- 보관함은 파일의 위치만 기억할 뿐, 넣는 것만으로는 아무것도 복사·이동되지 않습니다. **보관함에서 제거**와 **보관함 비우기**도 실제 파일에는 영향이 없습니다.
- 복사/이동은 일반 작업과 같이 진행률, 이름 충돌 확인, 실행 취소를 지원합니다. 이동에 성공한 항목은 보관함에서 빠집니다.
- 보관함의 내용은 모든 창이 함께 쓰며 앱을 다시 시작해도 유지됩니다. 표시 여부는 창마다 따로 정합니다.
- 다른 곳에서 삭제되거나 옮겨진 파일은 흐리게 표시되고 작업에서 건너뜁니다. 압축 파일 내부의 항목은 넣을 수 없습니다.

## 이름 붙인 탭 세션 (Tab Sessions)

현재 창의 탭 구성을 이름을 붙여 저장해 두었다가, 나중에 새 창으로 다시 엽니다.

**여는 방법**: **윈도우 ▸ 탭 세션 저장…**, **윈도우 ▸ 탭 세션**

1. 작업에 필요한 탭들을 열어 둡니다. 듀얼 창 분할, 창별 정렬과 보기 방식도 함께 저장됩니다.
2. **윈도우 ▸ 탭 세션 저장…**을 선택하고 이름을 입력한 뒤 **저장**을 누릅니다.
3. 나중에 **윈도우 ▸ 탭 세션**에서 세션을 고르면 저장한 탭들이 새 창으로 열립니다. 목록에는 탭 개수와 저장 시각이 함께 표시됩니다.
4. 이름을 바꾸거나 지우려면 **윈도우 ▸ 탭 세션 ▸ 세션 관리…**를 엽니다. 행을 선택하고 Return을 누르면 이름을 바꿀 수 있고, **삭제**로 삭제합니다.

- 세션은 항상 새 창으로 열리므로, 지금 열려 있는 창과 탭은 바뀌지 않습니다.
- 저장 후 사라진 폴더의 탭은 건너뛰고, 모든 폴더가 없으면 홈 탭 하나로 열립니다.
- 같은 이름으로 여러 번 저장할 수 있으며, 삭제는 확인 후 실행되고 되돌릴 수 없습니다.
- 앱을 다시 시작할 때 마지막 탭을 자동으로 복원하는 기능은 이와 별개인 무료 기능입니다.

## 사용 중인 앱 확인 (What's Using This?)

파일, 폴더, 드라이브를 붙잡고 있는 내 앱을 찾아 종료합니다. Windows의 PowerToys File Locksmith와 같은 기능입니다.

**여는 방법**: 드라이브가 꺼내지지 않거나 파일이 "사용 중"이라는 안내가 뜨면 안내 창의 **이 항목을 사용 중인 앱 확인**을 클릭합니다. 또는 파일·폴더나 사이드바의 드라이브를 오른쪽 클릭 ▸ **이 항목을 사용 중인 앱 확인**, 또는 **도구 ▸ 이 항목을 사용 중인 앱 확인**

1. 항목을 붙잡고 있는 앱이나 프로세스가 이름, 프로세스 ID(PID), 열고 있는 파일(셸이라면 그 폴더에서 작업 중이라는 표시)과 함께 표시됩니다.
2. **종료**를 누르면 앱을 일반 종료합니다. 앱이 저장 여부를 먼저 물을 수 있습니다. 종료되지 않으면 해당 줄에 "아직 실행 중"이 표시됩니다.
3. **강제 종료**는 응답하지 않는 앱 등을 즉시 종료합니다. 그 앱의 저장하지 않은 변경 사항이 사라지므로 먼저 확인을 받습니다.
4. 꺼내기나 작업이 실패해서 연 창이라면 **다시 시도**로 다시 시도합니다. 성공하면 창이 닫힙니다.

- 내 계정의 앱만 표시됩니다. 시스템 서비스, 다른 사용자, 네트워크의 다른 컴퓨터도 사용 중일 수 있으며 창에 그 안내가 함께 표시됩니다. 관리자 암호는 묻지 않습니다.
- Explorer 자신이 목록에 있다면(예: 미리보기 창에 표시 중인 PDF, 탐색 중인 드라이브) **Explorer에서 사용 중지**를 클릭합니다.
- 터미널 셸처럼 명령줄 프로세스는 강제 종료만 할 수 있습니다.
- **새로 고침**으로 다시 확인합니다.
- Pro가 없으면 "사용 중" 안내는 이전과 같습니다. **도구 ▸ 이 항목을 사용 중인 앱 확인**에는 **PRO** 표시가 붙습니다.

## iPhone·iPad 사진 (iPhone and iPad Photos)

케이블로 연결한 iPhone이나 iPad의 사진과 동영상을 탐색하고, Mac으로 복사하거나 폰에서 지울 수 있습니다. Windows의 **내 PC ▸ Apple iPhone**과 같은 방식이며, 폰에는 아무것도 설치할 필요가 없습니다.

**여는 방법**: 폰을 케이블로 연결하고 잠금을 해제한 뒤, 폰에서 묻는다면 **신뢰**를 누릅니다. 사이드바의 **위치** 아래에 폰이 나타납니다.

1. 사이드바에서 폰을 클릭하고 **내장 저장소 ▸ DCIM**으로 들어갑니다. 카메라 롤은 `202610_a`처럼 월별 폴더로 나뉘어 있으며, Windows에서 보던 것과 같습니다. 폴더마다 가장 최근에 찍은 사진의 날짜와 전체 크기가 표시됩니다.
2. 목록에는 사진과 동영상마다 이름, 촬영 날짜, 종류, 크기가 표시되고, 스크롤하면 썸네일이 나타납니다. 정렬, 필터 막대, 자세히·목록·아이콘 보기는 일반 폴더와 똑같이 동작합니다.
3. 사진을 선택하면 미리보기 창에 보이고, Space를 누르면 훑어보기(Quick Look)로, 더블클릭하면 기본 앱으로 열립니다.
4. Mac으로 복사하려면 파일을 폴더, 데스크탑, 사이드바, Finder, 웹 페이지의 업로드 영역으로 끌어다 놓습니다. ⌘C를 누른 뒤 일반 폴더에서 ⌘V를 눌러도 됩니다. 파일은 폰에 저장된 그대로, 촬영 날짜와 함께 복사됩니다.
5. 아직 가져오지 않은 사진을 모두 복사하려면 사이드바의 폰을 오른쪽 클릭 ▸ **사진 및 비디오 가져오기…**를 선택하고 폴더를 고릅니다(기본값은 사진 폴더). 사진은 폰 이름으로 된 폴더 안에 들어갑니다. 이름과 크기가 같은 파일이 이미 있으면 건너뛰므로, 새로 찍은 뒤 다시 실행해도 됩니다.
6. 폰에서 사진을 지우려면 사진을 선택하고 Delete를 누른 뒤, 확인 창에서 **삭제**를 클릭합니다. Return 키를 누르면 취소됩니다. 폴더를 지우면 그 안의 사진과 동영상이 모두 지워지며, 확인 창에 몇 개인지 표시됩니다. 지운 뒤에는 폴더도 목록에서 사라집니다.

- **폰에서 지운 사진은 되돌릴 수 없습니다.** 케이블로 지운 사진은 폰의 "최근 삭제된 항목" 앨범에도 남지 않으므로, 확인 창이 매번 나타납니다. 남겨 둘 사진은 먼저 복사해 두세요.
- 폰에 파일을 추가하거나 이름을 바꾸는 기능은 없습니다. 새 폴더, 이름 바꾸기, 붙여넣기, 폰으로 끌어다 놓기는 사용할 수 없습니다. iPhone에 사진을 넣으려면 AirDrop, iCloud 사진, Finder 동기화를 이용하세요.
- 폰이 잠겨 있으면 "iPhone의 잠금을 해제하고, 요청이 표시되면 신뢰를 누르세요."라는 안내가 표시되고, 잠금을 풀면 바로 목록이 나타납니다. 한 번 잠금을 푼 뒤에는 폰이 다시 잠겨도 케이블을 뽑기 전까지 계속 탐색하고 복사할 수 있습니다.
- 케이블을 뽑으면 해당 탭에 폰이 연결되어 있지 않다는 안내가 표시되고, 다시 꽂으면 자동으로 불러옵니다. 복사 중이었다면 복사가 멈추고 몇 개가 복사됐는지 알려 주며, 반쯤 복사된 파일은 남지 않습니다.
- iCloud에만 있는 사진("iPhone 저장 공간 최적화"를 켠 경우)은 폰에 없으므로 표시되지 않습니다.
- 파일은 원래 형식 그대로 복사됩니다. HEIC로 찍은 사진은 HEIC로 복사되며, macOS에서 그대로 열립니다. 편집한 사진은 원본 옆에 별도 파일(예: `IMG_E1234.JPG`)로 보이고, 라이브 포토는 사진과 짧은 동영상 두 파일로 보입니다.
- Pro가 없으면 사이드바의 폰에 **PRO** 배지가 붙고, 클릭하면 **자세히 알아보기** 버튼이 있는 짧은 안내가 표시됩니다.

## 속성 창 (Properties)

파일·폴더·여러 항목의 정보를 한 창에서 보고, 이름과 특성을 바꿀 수 있습니다. Windows의 **속성**(Alt+Enter)과 같은 기능입니다.

**여는 방법**: 항목을 선택하고 **⌥↩** 또는 **⌘I**, **파일 ▸ 속성**, 또는 오른쪽 클릭 ▸ **속성**

1. 파일이면 종류(예: "JPEG 이미지 (.jpg)"), 여는 앱, 위치, 바이트 단위까지 정확한 **크기**와 **디스크 할당 크기**, 만든 날짜·수정한 날짜·마지막으로 연 날짜가 표시됩니다.
2. 폴더면 **내용**에 안에 든 파일과 폴더 수("파일 1,204개, 폴더 37개")와 전체 크기가 표시됩니다. 백그라운드에서 세는 동안 숫자가 계속 올라가고, 창을 닫으면 세기를 멈춥니다. 앱 같은 패키지는 파일 하나로 셉니다.
3. 여러 항목을 선택하면 항목 수, 공통 종류(다르면 "여러 유형"), 들어 있는 폴더(다르면 "여러 위치"), 합계 크기가 표시됩니다.
4. 바꾸려면 이름을 고치거나, **읽기 전용**·**숨김**·**확장명 숨기기**를 켜고 끄거나, **연결 프로그램:** 옆 **변경…**으로 그 종류의 파일을 모두 열 앱을 고릅니다.
5. **적용**은 적용하고 창을 그대로 두며, **확인**은 적용하고 닫고, **취소**는 바꾸지 않고 닫습니다.
6. 파일이 손상되거나 바뀌지 않았는지 확인하려면 **SHA-256:** 옆 **계산**을 누릅니다. 백그라운드에서 파일을 읽으며 진행률을 보여 주고, **취소**로 멈출 수 있습니다. 끝나면 **복사**로 체크섬을 클립보드에 복사해 다운로드 페이지에 게시된 값과 비교하세요. 터미널의 `shasum -a 256`과 같은 값입니다.

- 여기서 바꾼 이름은 일반 이름 바꾸기와 같아서 ⌘Z로 되돌릴 수 있습니다. 이미 있는 이름이면 그렇다고 알려 주고, 입력한 이름은 그대로 남아 고쳐서 다시 적용할 수 있습니다.
- 특성 변경은 ⌘Z로 되돌릴 수 없습니다. 속성 창을 다시 열어 바꿔 주세요.
- **읽기 전용**은 macOS의 '잠금' 설정입니다. 이름이 점(.)으로 시작하는 항목은 항상 숨겨지므로 **숨김**을 끌 수 없습니다.
- 휴지통, 압축 파일 안, 폰의 항목은 보기만 할 수 있으며 버튼이 **닫기**로 표시됩니다.
- 속성 창은 여러 개를 동시에 열 수 있습니다.
- **SHA-256**은 파일 하나를 선택했을 때만 나옵니다. 폴더, 앱 같은 패키지, 심볼릭 링크, 여러 항목 선택에는 없습니다. 읽는 도중 파일이 바뀌면 값을 보여 주지 않으니 **계산**을 다시 누르세요. iCloud 등 클라우드에만 있는 파일은 계산하면서 내려받습니다.
- Pro가 없으면 **파일 ▸ 정보 가져오기**(⌘I 또는 ⌥↩)가 항목 하나의 읽기 전용 정보 창을 보여 줍니다. 종류, 여는 앱, 위치, 크기, 만든·수정한·마지막으로 연 날짜, 읽기 전용·숨김 여부가 나옵니다. 이 값을 바꾸는 것, 여러 항목을 한 번에 보는 것, 디스크에서 차지하는 크기, 폴더 안 항목 수 집계는 Pro에서 할 수 있습니다.

## 클라우드 파일 상태 (Cloud File Status)

iCloud Drive, Google Drive, OneDrive, Dropbox에서 어떤 파일이 온라인에만 있고 어떤 파일이 Mac에 있는지 보고, 둘 사이를 바꿀 수 있습니다. Windows OneDrive의 상태 표시와 같은 기능입니다.

**사용 방법**: 사이드바에서 iCloud Drive나 클라우드 저장소의 폴더를 엽니다. 파일 이름 뒤에 작은 배지가 붙습니다(아이콘 보기에서는 아이콘 왼쪽 아래).

1. 구름 윤곽선은 온라인 전용, 초록 체크는 Mac에 있음, 아래 화살표가 있는 구름은 내려받는 중, 위 화살표가 있는 구름은 아직 업로드가 끝나지 않았다는 뜻입니다.
2. Mac에 받아 두려면 파일을 선택하고 오른쪽 클릭 ▸ **다운로드** 또는 **파일 ▸ 다운로드**를 선택합니다.
3. 공간을 확보하려면 파일을 선택하고 오른쪽 클릭 ▸ **공간 확보** 또는 **파일 ▸ 공간 확보**를 선택합니다. 파일은 클라우드와 목록에 그대로 남고, 열면 다시 내려받습니다.
4. 폴더를 선택하면 그 안의 파일이 모두 포함됩니다.

- 공간 확보는 업로드가 끝난 파일의 Mac 사본만 지웁니다. 아직 업로드되지 않은 파일은 건너뛰고, 몇 개를 건너뛰었는지 알려 줍니다. 클라우드에서는 아무것도 지우지 않습니다.
- 다른 앱에서 열려 있거나 미리보기 창에 표시 중인 파일은 공간 확보가 안 될 수 있습니다. 닫고 다시 시도해 주세요.
- 실제 내려받기와 업로드는 각 서비스의 앱이 맡고, Explorer는 macOS에 요청만 합니다.
- 폴더에는 배지가 없으며, Google 문서·스프레드시트·프레젠테이션 파일은 온라인에만 있으므로 항상 구름 배지가 표시됩니다.
- Pro가 없으면 클라우드 폴더는 배지 없이 평소처럼 열리고, **파일 ▸ 다운로드**와 **파일 ▸ 공간 확보**에 **PRO** 배지가 표시됩니다.

## 바로 가기 만들기 (Create Shortcut)

파일이나 폴더의 바로 가기를 만듭니다. Windows의 **바로 가기 만들기**와 같으며, 원본을 옮겨도 따라가는 Finder 가상본(alias)으로 만들어집니다.

**사용 방법**: 항목을 선택하고 **⌃⌘A**, **파일 ▸ 바로 가기 만들기**, 또는 오른쪽 클릭 ▸ **바로 가기 만들기**

1. 각 항목 옆에 "*이름* - 바로 가기"이라는 바로 가기가 생기고 선택됩니다. 같은 이름이 있으면 (2), (3)처럼 번호가 붙습니다.
2. 다른 곳에 만들려면 **⌥⌘**를 누른 채 항목을 폴더나 목록의 빈 곳으로 끌어다 놓습니다. 포인터에 가상본 화살표가 표시됩니다.
3. ⌘Z를 누르면 새 바로 가기가 휴지통으로 가고, ⇧⌘Z로 다시 만들 수 있습니다.

- 휴지통, 압축 파일 안, 폰에서는 만들 수 없고, 쓰기 권한이 없는 폴더에는 놓을 수 없습니다.
- 폴더 바로 가기를 더블클릭하면 Explorer 안에서 그 폴더가 열립니다.

## 항목 체크박스 (Item Check Boxes)

항목마다 체크박스를 표시하고, 체크박스를 클릭해 파일을 고릅니다. Windows의 **보기 ▸ 항목 확인란**과 같은 기능이며, ⌘-클릭이 불편한 트랙패드에서 특히 편합니다.

**켜는 방법**: **보기 ▸ 항목 확인란** 또는 도구 막대의 **보기** 메뉴. 모든 창과 탭에 함께 적용됩니다.

1. 포인터가 올라간 항목과 선택한 항목에 체크박스가 나타납니다. 자세히·목록에서는 행 맨 앞, 아이콘 보기에서는 아이콘 왼쪽 위에 있습니다.
2. 체크박스를 클릭하면 그 항목이 선택에 추가되고, 다시 클릭하면 빠집니다. 나머지 선택은 그대로 유지되므로 ⌘를 누를 필요가 없습니다.
3. 항목의 이름이나 아이콘을 클릭하면 평소처럼 그 항목 하나만 선택됩니다.
4. 자세히 보기에서는 **이름** 머리글의 체크박스로 전체를 선택하고, 모두 선택된 상태에서 누르면 선택을 모두 해제합니다. 일부만 선택되어 있으면 가로줄(–)로 표시됩니다.

- 체크박스를 더블클릭해도 항목이 열리지 않습니다.
- **그룹화 방법**에서 일부 그룹을 접어 두면 머리글 체크박스는 보이는 항목만 선택합니다.
- 끄려면 **보기 ▸ 항목 확인란**을 다시 선택합니다.

## 미리 보기에서 텍스트 복사 (Copy Text)

텍스트 파일을 열지 않고 내용 전체를 클립보드에 복사합니다.

**사용 방법**: 미리 보기 창을 연 상태에서 텍스트·Markdown·RTF 파일을 선택하고, 미리 보기 위 파일 이름 오른쪽 끝의 복사 버튼을 클릭합니다.

1. 복사가 끝나면 버튼이 잠시 체크 표시로 바뀝니다.
2. 큰 파일이라 미리 보기에 앞부분만 보이더라도 파일 전체가 복사됩니다.
3. Markdown은 원본 텍스트로 복사됩니다. RTF는 서식과 함께 복사되어 Pages·Word·메일에는 서식이 유지된 채, 그 밖의 곳에는 일반 텍스트로 붙여넣어집니다. **소스 보기**를 켜 둔 상태에서는 RTF 원본이 복사됩니다.

- 미리 보기 창이 텍스트로 보여 주는 파일에 버튼이 나타납니다: 일반 텍스트, Markdown, RTF, 소스 코드, JSON, XML, CSV, HTML, 로그.
- 32MB가 넘는 파일은 이 방법으로 복사할 수 없습니다.
- 10MB가 넘는 RTF 파일은 Quick Look으로 표시되며, 복사 버튼과 **소스 보기**가 나타나지 않습니다.
- 일부만 복사하려면 미리 보기에서 텍스트를 선택하고 ⌘C를 누릅니다.

## 라이선스가 해제되면

환불 등으로 라이선스를 제거해도 저장된 검색, 탭 세션, 보관함 목록 같은 데이터는 지워지지 않고 이 Mac에 남아 있으며, 다시 라이선스를 등록하면 그대로 사용할 수 있습니다. 무료 기능은 계속 정상적으로 동작합니다. 궁금한 점은 [자주 묻는 질문](/explorer/guide/faq/)을 확인하거나 support@yjlab.io로 문의해 주세요.
