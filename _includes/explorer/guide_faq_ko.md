# 자주 묻는 질문과 문제 해결

Explorer for Mac을 사용하면서 자주 받는 질문과, 문제가 생겼을 때 먼저 확인할 내용을 모았습니다. 앱 화면은 영어로 표시되므로 메뉴와 버튼 이름은 앱에 보이는 그대로 적었습니다. 여기서 답을 찾지 못하셨다면 support@yjlab.io 로 문의해 주세요.

## 일반

### Explorer는 Finder를 대체하나요?

아닙니다. Explorer는 Finder와 **함께** 실행되는 별도의 파일 관리자입니다. Finder를 끄거나 바꾸지 않으며, 시스템 설정도 변경하지 않습니다. 평소 파일 탐색과 정리는 Explorer로 하고, Finder는 그대로 두셔도 됩니다.

### 무료 버전과 Pro는 무엇이 다른가요?

무료 버전만으로도 폴더 트리, 탭, 즐겨찾기, Details 보기, 복사·이동·이름 바꾸기, 실행 취소, 휴지통 복원, 네트워크 드라이브 등 일상적인 파일 관리를 모두 할 수 있습니다. 무료로 제공되던 기능은 앞으로도 계속 무료이며, 기간 제한이나 업그레이드 권유 팝업도 없습니다.

Pro는 일괄 이름 바꾸기, 폴더 비교·동기화, 디스크 사용량 분석, 듀얼 패널, ZIP 열람·압축 같은 고급 도구를 추가하는 1회 구매 업그레이드입니다. 자세한 내용은 [Explorer Pro 안내](/explorer/guide/pro/)를 참고하세요.

### 어떤 Mac에서 사용할 수 있나요?

**macOS 14 Sonoma 이상**이 필요하며, Apple 실리콘 Mac과 Intel Mac 모두에서 실행됩니다.

### 설치는 어떻게 하나요?

1. 다운로드한 DMG 파일을 엽니다.
2. **Explorer** 아이콘을 **Applications** 폴더로 드래그합니다.
3. 응용 프로그램 폴더에서 Explorer를 실행합니다.

DMG 창에서 바로 실행하면 업데이트가 동작하지 않으므로, 앱이 응용 프로그램 폴더로 옮기겠느냐고 묻습니다. **Move to Applications Folder**를 누르면 앱이 스스로 옮겨진 뒤 다시 실행됩니다. 처음 사용하는 방법은 [시작하기](/explorer/guide/getting-started/)에서 자세히 안내합니다.

### Windows에서 쓰던 키가 다르게 동작해요.

Mac 키보드와 macOS 관례 때문에 몇 가지가 다릅니다.

- **Delete(⌫) 키**는 삭제가 아니라 상위 폴더로 이동합니다(Windows의 Backspace와 같음). 삭제는 **⌘⌫** 또는 **fn+⌫**(Forward Delete)입니다.
- **이름 바꾸기**는 **⌘R**입니다. Mac에서는 F2가 대부분 화면 밝기 키로 쓰이기 때문입니다.
- **Return(Enter)** 은 선택한 항목을 엽니다.

전체 목록은 [키보드 단축키](/explorer/guide/shortcuts/)를 참고하세요.

## 권한

### 왜 데스크탑, 문서, 다운로드 폴더 접근 권한을 묻나요?

macOS는 개인정보 보호를 위해 앱이 데스크탑, 문서, 다운로드 같은 폴더를 처음 열 때 사용자에게 허락을 받도록 합니다. 이 안내는 Explorer가 아니라 macOS가 띄우는 것이며, **허용**을 눌러야 해당 폴더의 파일을 볼 수 있습니다. 폴더마다 한 번씩만 묻습니다.

### 실수로 "허용 안 함"을 눌렀어요. 다시 허용하려면 어떻게 하나요?

macOS는 한 번 거부한 권한을 다시 묻지 않으므로 직접 켜야 합니다.

1. 접근이 막힌 폴더에서 Explorer가 보여 주는 **Open Privacy Settings…** 버튼을 누르거나, **시스템 설정 ▸ 개인정보 보호 및 보안 ▸ 파일 및 폴더**를 엽니다.
2. 목록에서 **Explorer**를 찾아 필요한 폴더의 스위치를 켭니다.
3. Explorer에서 해당 폴더를 다시 엽니다.

### 전체 디스크 접근 권한이 꼭 필요한가요?

일반적인 사용에는 필요하지 않습니다. 다음과 같이 macOS가 특별히 보호하는 위치를 볼 때만 필요합니다.

- 휴지통(`~/.Trash`)
- `~/Library` 안의 일부 폴더(메일 데이터 등)
- Time Machine 내부 등 시스템 보호 영역

이런 위치를 열면 Explorer가 안내 문구와 함께 **Open Full Disk Access…** 버튼을 보여 줍니다. **시스템 설정 ▸ 개인정보 보호 및 보안 ▸ 전체 디스크 접근 권한**에서 **Explorer**를 켠 뒤, 안내에 따라 앱을 다시 실행하세요. Explorer는 이 권한을 스스로 요청하거나 켜지 않으며, 안내만 합니다.

### 폴더 크기가 "—"로 표시돼요.

`~/Library`와 휴지통은 macOS 권한 안내가 반복해서 뜨지 않도록 기본적으로 크기를 계산하지 않고 "—"로 표시합니다. Explorer에 전체 디스크 접근 권한을 주면 다른 폴더처럼 크기가 표시됩니다.

### Explorer가 관리자 암호를 요구하거나 시스템 보호를 우회하나요?

아닙니다. Explorer는 관리자(root) 권한을 요청하지 않으며, macOS의 개인정보 보호(TCC)나 시스템 무결성 보호를 우회하지 않습니다. 직접 배포를 위해 App Store 샌드박스 없이 배포되지만, 접근할 수 있는 범위는 macOS 개인정보 보호 설정에서 사용자가 허용한 만큼으로 제한됩니다. 앱은 Apple의 공증(notarization)을 받았습니다.

### "네트워크 볼륨의 파일에 접근하려고 합니다"라는 안내가 떠요.

NAS나 공유 폴더를 처음 열 때 macOS가 띄우는 권한 안내입니다. **허용**을 누르면 됩니다. 거부했다면 **시스템 설정 ▸ 개인정보 보호 및 보안 ▸ 파일 및 폴더**의 **Explorer** 항목에서 **네트워크 볼륨**을 켜세요.

## 네트워크 드라이브와 NAS (SMB)

### NAS나 Windows 공유 폴더에는 어떻게 연결하나요?

처음 연결은 macOS의 기능으로 합니다.

1. Finder에서 **이동 ▸ 서버에 연결**(⌘K)을 선택합니다.
2. `smb://서버주소/공유이름` 형식으로 주소를 입력하고 연결합니다.
3. 연결되면 Explorer 사이드바의 **Locations**에 공유가 나타납니다.

Explorer의 주소 표시줄에는 `smb://` 주소를 직접 입력할 수 없습니다. 한 번 연결한 공유는 Explorer가 기억하므로, 이후에는 사이드바에서 바로 다시 연결할 수 있습니다.

### 사이드바의 네트워크 공유가 흐리게 표시돼요.

macOS가 한동안 사용하지 않은 공유를 자동으로 연결 해제한 상태입니다. Windows의 네트워크 드라이브 연결처럼, Explorer는 연결이 끊긴 공유도 **Locations**에 흐리게 남겨 둡니다. 클릭하면 시스템을 통해 다시 연결되고 바로 그 공유가 열립니다. 더 이상 쓰지 않는 공유는 마우스 오른쪽 버튼을 눌러 **Forget Network Location**을 선택하면 목록에서 지워집니다.

### Explorer가 NAS 비밀번호를 저장하나요?

아닙니다. Explorer는 비밀번호를 묻거나 저장하지 않습니다. 다시 연결할 때는 macOS 키체인에 저장된 정보가 사용되고, 저장된 정보가 없으면 macOS가 직접 로그인 창을 띄웁니다.

### 네트워크 폴더가 느려요.

네트워크 폴더는 로컬 디스크보다 목록을 읽는 데 시간이 걸립니다. 목록을 불러오는 동안에는 **Loading…** 표시가 나타납니다. 다음을 확인해 보세요.

- 최신 버전으로 업데이트하세요. 같은 공유 안에서 파일을 옮기는 속도와 대용량 작업 중 목록 갱신이 여러 차례 개선되었습니다.
- Wi‑Fi보다 유선 연결이 훨씬 안정적입니다.
- 같은 작업이 Finder에서도 느리다면 네트워크나 서버 쪽 문제일 가능성이 높습니다.

### Windows 11 공유에서 잘라내기·붙여넣기 후 폴더가 열리지 않아요.

최신 macOS에서 Windows 11 공유 폴더로 파일을 이동한 뒤 폴더가 "열 수 없음"으로 표시되는 경우가 있습니다. 이는 **macOS SMB 클라이언트의 캐시 문제**로, Finder에서도 똑같이 발생하며 **파일이 손상된 것은 아닙니다.**

1. 사이드바에서 해당 공유를 추출(eject)합니다.
2. 공유에 다시 연결합니다. 폴더가 정상적으로 열립니다.

같은 문제가 자주 반복된다면 고급 사용자는 macOS의 SMB 디렉터리 캐시를 끌 수 있습니다. 터미널에서 관리자 권한으로 `/etc/nsmb.conf` 파일을 만들고 아래 내용을 넣은 뒤, 공유를 다시 연결하세요.

```
[default]
dir_cache_off=yes
```

이 설정은 Explorer가 아니라 Mac 전체의 SMB 연결에 적용되며, 파일을 지우면 원래대로 돌아갑니다.

### 네트워크 폴더에서 삭제하면 "Delete Permanently?"라고 물어요.

네트워크 공유와 일부 외장 디스크에는 휴지통이 없습니다. 이런 곳에서 삭제하면 Explorer는 Windows 탐색기처럼 영구 삭제 여부를 먼저 확인합니다. **Delete Permanently**를 누르면 즉시 삭제되며 **실행 취소할 수 없습니다.** 안전한 쪽이 기본 버튼으로 선택되어 있습니다.

### 공유 폴더에 `.smbdelete`로 시작하는 파일이 남아요.

다른 프로그램이 파일을 열고 있는 동안 삭제하면 SMB 서버가 남기는 임시 파일입니다. Explorer는 삭제 전에 미리 보기를 닫고, 삭제 후에는 남은 임시 파일을 조용히 정리합니다. 다른 앱이 계속 사용 중인 파일은 건드리지 않으므로, 그 앱을 닫으면 사라집니다.

## 파일 작업

### 실수로 옮기거나 지운 파일을 되돌릴 수 있나요?

네. **Edit ▸ Undo**(⌘Z)로 이름 바꾸기, 이동, 휴지통으로 이동, 복사를 되돌릴 수 있고, **Edit ▸ Redo**(⌘⇧Z 또는 ⌘Y)로 다시 실행할 수 있습니다.

- 창마다 최근 10개 작업까지 기억합니다.
- 앱을 종료하면 실행 취소 기록은 사라집니다.
- 휴지통이 없는 곳에서의 영구 삭제는 되돌릴 수 없습니다.
- 그 사이 다른 파일이 같은 이름으로 생겼다면, 그 파일을 덮어쓰지 않도록 해당 항목의 실행 취소를 건너뜁니다.

### 휴지통으로 보낸 파일을 원래 위치로 복원하려면 어떻게 하나요?

1. **Go ▸ Edit Path**(⌘L)를 누르고 `~/.Trash`를 입력해 휴지통을 엽니다. 휴지통을 보려면 전체 디스크 접근 권한이 필요합니다. <!-- TODO 확인: 숨김 파일 표시가 꺼진 상태에서도 주소 입력으로 ~/.Trash 이동이 되는지 -->
2. 복원할 항목을 선택합니다.
3. 마우스 오른쪽 버튼을 누르고 **Restore**를 선택하거나 **File ▸ Restore**를 선택합니다.

Finder나 다른 앱이 휴지통으로 보낸 항목도 복원할 수 있습니다. 원래 위치를 알 수 없는 항목은 건너뛰고 결과를 알려 드립니다. 휴지통 안에서는 **Move to Trash** 대신 **Delete Immediately…** 로 영구 삭제할 수 있습니다.

### 숨김 파일을 보려면 어떻게 하나요?

**View ▸ Show Hidden Files**(⌘⇧.)를 선택하세요. 다시 선택하면 숨겨집니다.

### 파일 확장자가 보이지 않아요.

**Explorer ▸ Settings…**(⌘,)의 **General**에서 **Always show file extensions**를 켜세요. 기본으로 켜져 있으며, 켜져 있으면 macOS가 확장자를 숨기도록 표시한 파일도 Windows처럼 확장자를 보여 줍니다.

### 붙여넣을 곳에 같은 이름의 파일이 있으면 어떻게 되나요?

확인 창이 뜨고 세 가지 중 하나를 고를 수 있습니다.

- **Keep Both**(기본): 새 항목의 이름을 바꿔 둘 다 남깁니다(예: `file 2.txt`).
- **Skip**: 이 항목은 건너뜁니다.
- **Replace**: 기존 항목을 휴지통으로 보내고 새 항목으로 바꿉니다.

**Apply to all remaining items**를 선택하면 남은 충돌에도 같은 선택을 적용합니다.

### ZIP 파일은 어떻게 다루나요?

무료 버전에서는 ZIP 파일을 더블클릭하면 macOS 기본 앱(아카이브 유틸리티 등)으로 열립니다. Pro에서는 ZIP 파일을 압축을 풀지 않고 폴더처럼 열어 보고, 안의 파일을 미리 보거나 복사해 낼 수 있습니다(읽기 전용). 선택한 파일을 **File ▸ Compress to ZIP**으로 압축하거나 **Compress with Password…** 로 AES-256 암호를 걸어 압축할 수도 있습니다. 암호가 걸린 ZIP은 Keka, 7-Zip처럼 AES 암호화를 지원하는 프로그램으로 풀 수 있습니다. <!-- TODO 확인: macOS 아카이브 유틸리티 / Windows 11 기본 탐색기에서 AES-256 ZIP 해제 가능 여부 -->

## 업데이트

### 새 버전으로 업데이트하려면 어떻게 하나요?

**Explorer ▸ Check for Updates…** 를 선택하세요. 새 버전이 있으면 Explorer가 내려받아 서명을 확인한 뒤 스스로 교체하고 다시 실행합니다. 웹사이트에서 다시 내려받을 필요가 없습니다.

자동 확인은 **Explorer ▸ Settings…** 의 **Updates**에서 **Check for updates automatically**로 켜고 끌 수 있습니다. 자동 확인이 켜져 있어도 업데이트 파일은 설치에 동의한 뒤에만 내려받으며, 복사나 이동이 진행 중일 때는 방해하지 않습니다.

### 업데이트가 설치되지 않아요.

DMG 창에서 앱을 직접 실행하고 있다면 업데이트가 설치될 수 없습니다. 안내 창에서 **Move to Applications Folder**를 누르거나, 앱을 종료한 뒤 **Applications** 폴더로 옮겨서 실행하세요. 그래도 안 되면 [웹사이트](/explorer/)에서 최신 DMG를 내려받아 덮어 설치하셔도 설정은 그대로 유지됩니다.

## 라이선스와 구매

### Pro 라이선스는 어디에 입력하나요?

**Explorer ▸ Settings…** 의 **Explorer Pro**에서 **Import License…** 로 라이선스 파일을 가져오거나, 라이선스를 붙여 넣으면 됩니다. 라이선스는 Mac 안에서 오프라인으로 확인되며 서버에 접속하지 않습니다. 기기 이전, 재설치 등 자세한 내용은 [라이선스 안내](/explorer/guide/license/)를 참고하세요.

### 환불받을 수 있나요?

구매일로부터 14일 이내라면 사유와 관계없이 전액 환불해 드립니다. 자세한 기준은 [환불정책](/explorer/refund/)을 참고하세요.

## 제거와 개인정보

### Explorer를 완전히 제거하려면 어떻게 하나요?

1. Explorer를 종료합니다.
2. **응용 프로그램** 폴더의 **Explorer**를 휴지통으로 드래그합니다.
3. 설정과 저장된 데이터까지 지우려면 아래 항목도 삭제합니다.
   - `~/Library/Preferences/io.yjlab.Explorer.plist` (보기, 탭, 즐겨찾기 등 설정)
   - `~/Library/Application Support/io.yjlab.Explorer/` (기억한 네트워크 공유, 휴지통 원래 위치 기록, Pro 라이선스)
   - `~/Library/Caches/io.yjlab.Explorer/` (있는 경우)

Pro 라이선스 파일도 함께 지워지므로, 나중에 다시 설치할 계획이라면 구매 시 받은 라이선스를 보관해 두세요. 앱에 준 권한 항목은 **시스템 설정 ▸ 개인정보 보호 및 보안**에서 지울 수 있습니다.

### Explorer가 내 파일이나 사용 기록을 수집하나요?

아닙니다. Explorer에는 분석·추적 도구(텔레메트리)가 없고, 계정도 필요하지 않습니다. 파일 이름, 경로, 사용 기록은 Mac 밖으로 나가지 않습니다. 앱이 인터넷에 접속하는 경우는 업데이트 확인뿐이며, 이것도 설정에서 끌 수 있습니다. 주소 표시줄에 입력한 경로 기록은 **Settings…** 의 **Privacy**에서 **Remember typed addresses**를 끄거나 **Clear Typed History**로 지울 수 있습니다. 자세한 내용은 [개인정보처리방침](/explorer/privacy/)을 참고하세요.
