# Explorer for Mac 사용 가이드

Explorer for Mac은 Windows 파일 탐색기에 익숙한 분들을 위한 macOS 파일 관리자입니다. 처음 사용하신다면 **시작하기**부터 읽어 보세요.

## 가이드

- **[시작하기](/explorer/guide/getting-started/)** — 설치, 화면 구성, 자주 쓰는 작업, Windows 탐색기와 다른 점
- **[키보드 단축키](/explorer/guide/shortcuts/)** — 전체 단축키와 Windows 탐색기 대응표
- **[Explorer Pro 기능 사용법](/explorer/guide/pro/)** — Pro 기능별 사용 방법
- **[라이선스 가이드](/explorer/guide/license/)** — 구매, 라이선스 적용, 새 Mac으로 옮기기, 환불
- **[자주 묻는 질문](/explorer/guide/faq/)** — 권한, 네트워크 드라이브, 업데이트, 문제 해결
