# Explorer for Mac 시작하기

Explorer for Mac은 Windows 11 파일 탐색기의 화면 구성을 macOS로 옮긴 앱입니다. 왼쪽에는 폴더 트리, 위쪽에는 탭, 그리고 직접 입력할 수 있는 주소창과 열별로 정렬되는 자세히(Details) 보기가 있습니다. 이 가이드는 설치부터 화면 구성, 그리고 매일 쓰는 작업까지 차례로 안내합니다.

이 문서에서 설명하는 기능은 모두 무료입니다. 전체 단축키 목록은 [키보드 단축키](/explorer/guide/shortcuts/)에서 보실 수 있습니다.

## 1. 설치와 첫 실행

macOS 14 Sonoma 이상이 필요하며, Apple Silicon과 Intel Mac에서 모두 실행됩니다.

1. [Explorer for Mac 페이지](/explorer/)에서 DMG를 내려받아 엽니다.
2. **Explorer** 아이콘을 **Applications** 폴더로 드래그합니다.
3. 응용 프로그램 폴더나 Launchpad에서 Explorer를 실행합니다.

디스크 이미지에서 바로 실행하면 앱을 응용 프로그램 폴더로 옮기겠느냐고 묻습니다. 디스크 이미지에서는 앱 내 업데이트가 동작하지 않으니 옮기시기를 권장합니다.

### 폴더 접근 권한

Explorer에는 자체 설정 마법사나 권한 요청 창이 없습니다. 홈 폴더와 드라이브는 바로 둘러보실 수 있습니다. 다만 macOS가 보호하는 위치는 다음과 같이 처리됩니다.

- **Desktop**, **Documents**, **Downloads** 폴더나 네트워크 볼륨을 처음 열면 macOS가 직접 접근 허용 여부를 묻습니다. **허용**을 누르시면 macOS가 이 선택을 기억합니다.
- **허용 안 함**을 누르셨다면 해당 폴더에 목록 대신 안내 문구와 **Open Privacy Settings…** 버튼이 나타납니다. **시스템 설정 ▸ 개인정보 보호 및 보안**에서 Explorer를 다시 허용하시면 정상적으로 열립니다.
- `~/Library`나 휴지통 같은 일부 시스템 영역은 **전체 디스크 접근 권한**(**시스템 설정 ▸ 개인정보 보호 및 보안 ▸ 전체 디스크 접근 권한**)이 있어야 모두 읽을 수 있습니다. 이 권한은 선택 사항입니다. 허용하지 않으면 해당 폴더의 크기가 "—"로 표시됩니다.

### 업데이트

**Explorer ▸ Check for Updates…**를 선택하면 언제든 업데이트하실 수 있습니다. 자동 확인은 **Settings ▸ Updates**에서 끌 수 있습니다.

## 2. 화면 둘러보기

### 사이드바

왼쪽 사이드바는 Windows의 탐색 창에 해당하며 항상 표시됩니다.

- **Home**: **Favorites**, **Recent locations**(최근에 방문한 폴더), **Drives**를 모아 보여 주는 시작 화면입니다. 복원할 위치가 없는 새 창은 이 화면으로 열립니다.
- **Gallery**: 지정한 폴더의 사진과 동영상을 최신순 썸네일로 보여 줍니다. 기본 소스는 Pictures 폴더이며, Gallery의 소스 메뉴에서 **Add Source…**를 선택해 폴더를 더 추가할 수 있습니다.
- **Favorites**: Desktop, Downloads, Documents, Pictures, Music, Videos가 기본으로 고정되어 있고, 직접 고정한 폴더도 함께 표시됩니다. 드래그로 순서를 바꿀 수 있습니다.
- **Locations**: 홈 폴더, Macintosh HD, 외장 드라이브, 네트워크 공유가 펼칠 수 있는 폴더 트리로 표시됩니다. 꺼낼 수 있는 드라이브에는 추출 버튼이 있습니다.

트리가 현재 위치를 따라가는 방식은 **View** 메뉴의 **Expand to Open Folder**와 **Show All Folders ("Expand Opened Folder")**로 정합니다. Windows 탐색 창의 같은 옵션에 해당합니다.

### 탭

창마다 탭 막대가 있으며, 탭이 하나뿐이어도 표시됩니다. 탭마다 폴더, 방문 기록, 선택 항목, 정렬, 검색 상태가 따로 유지됩니다.

- **+** 버튼을 누르거나 **⌘T**를 누르면 현재 폴더로 새 탭이 열립니다.
- 폴더를 오른쪽 클릭하고 **Open in New Tab**을 선택하면 백그라운드 탭으로 열립니다.
- 탭을 드래그해 순서를 바꾸거나, 탭 막대 밖으로 끌어내 별도 창으로 분리할 수 있습니다.
- 탭을 가운데 클릭하거나 오른쪽 클릭 후 **Close Tab**을 선택하면 닫힙니다. 같은 메뉴에 **Move Tab to New Window**도 있습니다.

앱을 다시 실행하면 창과 탭이 그대로 복원됩니다.

### 도구 막대

도구 막대는 Windows 11의 명령 모음처럼 파일 목록 바로 위에 있습니다. 왼쪽부터 **Back**, **Forward**, **Up**, **New Folder**, **Cut**, **Copy**, **Paste**, **Rename**, **Share**, **Move to Trash**, **Sort**, **View** 순서이며, 오른쪽 끝에 **Preview** 버튼이 있습니다.

### 주소창

주소창은 현재 경로를 클릭할 수 있는 구간(브레드크럼)으로 보여 줍니다. 구간을 클릭하면 그 폴더로 이동합니다.

경로를 직접 입력하는 방법은 다음과 같습니다.

1. **⌘L**을 누르거나, **Go ▸ Edit Path**를 선택하거나, 경로 오른쪽 빈 공간을 클릭합니다.
2. `/Volumes/Backup`이나 `~/Projects` 같은 경로를 입력합니다. 이전에 입력한 위치가 아래에 추천되며, **↓**로 고를 수 있습니다.
3. **Return**을 누르면 이동하고, **Esc**를 누르면 취소됩니다.

입력한 주소를 기억하지 않게 하거나 기록을 지우려면 **Settings ▸ Privacy**를 이용하세요.

### 검색 상자

주소창 오른쪽의 검색 상자에는 현재 폴더 이름이 표시됩니다(예: "Search Downloads"). 입력하는 대로 현재 폴더의 항목을 이름으로 걸러 줍니다. `*.pdf`처럼 와일드카드를 쓰면 Windows처럼 전체 이름 기준으로 찾습니다. **Esc**를 누르면 검색이 지워지고 전체 목록이 다시 표시됩니다. **⌘F**를 누르면 검색 상자로 바로 이동합니다.

무료 검색은 현재 폴더만 대상으로 합니다. 하위 폴더 전체 검색은 Pro 기능입니다.

### 파일 목록과 보기 방식

도구 막대의 **View** 메뉴에서 보기 방식을 바꿉니다. Windows처럼 폴더마다 고른 보기 방식이 따로 기억됩니다.

- **Details**: 열별로 정렬할 수 있는 표 형식이며 기본 보기입니다.
- **List**: 이름만 빽빽하게 나열합니다.
- **Extra Large Icons**, **Large Icons**, **Medium Icons**, **Small Icons**: 사진과 동영상을 썸네일로 보여 주는 격자 보기입니다.

Details 보기에서는 **Size** 열에 폴더 크기가 자동으로 채워지고, Finder 색상 태그는 색 점으로 표시됩니다.

### 미리 보기 창

**⇧⌘P**를 누르거나, **View ▸ Show Preview Pane**을 선택하거나, 도구 막대의 **Preview**를 클릭합니다. 오른쪽 창에 선택한 항목의 미리 보기(이미지, PDF, 텍스트, Markdown, 동영상, Quick Look을 통한 Office 문서)와 함께 크기, 날짜, 이미지 해상도, 카메라 정보 같은 세부 정보가 표시됩니다. 구분선을 드래그해 너비를 조절할 수 있습니다.

파일을 선택하고 **Space**를 누르면 큰 Quick Look 창으로 볼 수 있습니다.

### 상태 표시줄

아래쪽 상태 표시줄에는 폴더의 항목 수가 표시됩니다. 항목을 선택하면 선택 개수(예: "3 of 128 selected")와 합계 크기가 함께 나타나고, 폴더를 선택하면 그 크기를 백그라운드에서 계산합니다.

## 3. 자주 하는 작업

### 이동하고 열기

- 폴더를 더블클릭하거나 **Return**을 누르면 열립니다. 파일은 기본 앱으로 열립니다. Windows처럼 **Return**은 '열기'이며, Finder처럼 이름 바꾸기가 시작되지 않습니다.
- 상위 폴더로 이동하려면 **Backspace(⌫)**나 **⌘↑**를 누르거나 도구 막대의 **Up**을 클릭합니다. 방금 나온 폴더가 선택된 상태로 남습니다.
- 뒤로/앞으로는 **⌘[** / **⌘]**입니다.
- 이름의 첫 글자들을 입력하면 해당 항목으로 바로 이동합니다.
- 폴더를 가리키는 가상본(alias)과 심볼릭 링크는 Explorer 안에서 열립니다. 앱 같은 패키지는 파일처럼 열리며, 안을 보려면 오른쪽 클릭 후 **Show Package Contents**를 선택합니다.

### 새 폴더와 새 파일

- **새 폴더**: **⇧⌘N**을 누르거나 **File ▸ New Folder**를 선택합니다. 이름을 입력하고 **Return**을 누릅니다.
- **새 텍스트 문서**: **File ▸ New Text Document**를 선택하거나 폴더의 빈 곳을 오른쪽 클릭해 선택합니다. 빈 `.txt` 파일이 이름 입력 상태로 만들어집니다.

### 복사, 잘라내기, 붙여넣기

**Ctrl** 대신 **⌘**를 쓴다는 점만 빼면 Windows와 같습니다.

1. 항목을 선택하고 **⌘C**(복사) 또는 **⌘X**(잘라내기)를 누릅니다. 잘라낸 항목은 흐리게 표시됩니다.
2. 대상 폴더를 열고 **⌘V**를 누릅니다.
3. 붙여 넣은 항목이 선택된 상태가 되므로 어디에 들어갔는지 바로 확인하실 수 있습니다.

잘라내기를 취소하려면 **Esc**를 누릅니다. 같은 이름이 이미 있으면 **Replace**, **Keep Both**, **Skip** 중에서 고르실 수 있고, **Apply to all remaining items**를 선택하면 나머지 항목에도 같은 선택이 적용됩니다. 큰 파일을 복사할 때는 속도, 남은 시간, 취소 버튼이 있는 진행 창이 표시됩니다.

### 이름 바꾸기

항목 하나를 선택하고 **⌘R**을 누르거나 **Edit ▸ Rename**을 선택합니다. 확장자를 뺀 이름 부분만 선택되며, **Return**을 누르면 확정되고 **Esc**를 누르면 취소됩니다.

### 삭제와 복원

- **⌘⌫**나 **⌦**(fn + Delete)를 누르거나 **Move to Trash**를 선택하면 항목이 휴지통으로 이동합니다. macOS의 휴지통은 Windows의 휴지통(Recycle Bin)에 해당합니다.
- **⌫** 단독으로는 아무것도 삭제되지 않으며, 상위 폴더로 이동할 뿐입니다.
- 일부 네트워크 볼륨처럼 휴지통이 없는 위치에서는 영구 삭제 전에 확인을 받습니다.
- 복원하려면 휴지통을 열고 항목을 선택한 뒤, 오른쪽 클릭 메뉴나 **File** 메뉴에서 **Restore**를 선택합니다. 각 항목이 원래 있던 폴더로 돌아갑니다. 휴지통 안에서는 **Move to Trash**가 **Delete Immediately…**로 바뀝니다.

휴지통을 열려면 **⌘L**을 누르고 `~/.Trash`를 입력한 뒤 **Return**을 누릅니다. 목록을 보려면 전체 디스크 접근 권한이 필요합니다. <!-- TODO 확인: Trash 진입 경로가 주소창(~/.Trash) 외에 사이드바/메뉴로 있는지 -->

### 실행 취소와 다시 실행

**⌘Z**를 누르면 마지막 파일 작업이 취소됩니다. 이름 바꾸기, 이동, 복사, 휴지통으로 이동, 복원, 새 폴더, 새 텍스트 문서가 대상입니다. 다시 실행은 **⇧⌘Z** 또는 **⌘Y**입니다. **Edit** 메뉴에는 **Undo Rename**처럼 무엇이 취소되는지 표시됩니다.

### 드래그 앤 드롭

- 같은 드라이브 안에서는 이동하고, 다른 드라이브로는 복사합니다. 놓을 때 **⌥(Option)**를 누르고 있으면 이동 대신 복사합니다.
- 목록의 폴더, 사이드바 트리, 즐겨찾기, 주소창의 경로 구간에 놓을 수 있습니다.
- 다른 탭으로 옮기려면 그 탭 위에 끌어다 잠시 기다립니다. 탭이 열리면 목록에 놓습니다.
- Finder나 다른 앱과도 평소처럼 드래그 앤 드롭할 수 있습니다.

### 즐겨찾기 고정

목록이나 트리에서 폴더를 오른쪽 클릭해 **Add to Favorites**를 선택하거나, 폴더를 Favorites 영역으로 드래그합니다. 고정을 풀려면 **Remove from Favorites**를 선택합니다. **Restore Default Favorites**를 선택하면 기본 폴더들이 다시 고정됩니다.

### 네트워크 드라이브

NAS나 SMB 공유는 Finder의 **이동 ▸ 서버에 연결…** 등으로 한 번 연결해 두면, Explorer가 **Locations**에 기억해 둡니다. Windows의 네트워크 드라이브 연결과 비슷합니다. macOS가 유휴 상태의 공유 연결을 끊어도 흐리게 표시된 채 목록에 남아 있으며, 클릭하면 다시 연결됩니다. 암호는 키체인에서 가져옵니다. 더 이상 쓰지 않는 공유는 오른쪽 클릭 후 **Forget Network Location**을 선택해 지웁니다.

### 그 밖의 오른쪽 클릭 메뉴

**Open With**, **Open in New Window**, **Duplicate**, **Copy Path**(**⌥⌘C**), **Open in Terminal**, **Share**, **Get Info**, **Show in Finder**, **Refresh**도 있습니다. **Open in Terminal**에 사용할 터미널 앱은 **Settings ▸ Terminal**에서 고릅니다.

## 4. 사용자 설정

- **정렬**: 열 머리글을 클릭하면 그 열로 정렬되고, 다시 클릭하면 순서가 반대로 바뀝니다. 도구 막대의 **Sort** 버튼으로도 정렬할 수 있습니다.
- **폴더 먼저 표시**: 기본적으로 폴더는 항상 파일보다 위에 표시됩니다. **Settings ▸ General ▸ Always show folders first**를 끄면 Windows 규칙을 따릅니다. 폴더끼리는 계속 모여 있지만, 내림차순으로 정렬하면 맨 아래로 이동합니다.
- **열 선택**: Details 보기에서 열 머리글을 오른쪽 클릭해 표시할 열을 선택합니다. **Date Modified**, **Date Created**, **Date Accessed**, **Date Added**, **Type**, **Extension**, **Size** 중에서 고를 수 있으며, **Name** 열은 항상 표시됩니다. 머리글을 드래그하면 순서가 바뀌고, 경계를 드래그하면 너비가 바뀝니다. 이 설정은 모든 창에 적용됩니다.
- **Compact View**: 기본 행 간격은 Windows 11처럼 여유 있게 설정되어 있습니다. 도구 막대의 **View** 메뉴에서 **Compact View**를 선택하면 List와 Details의 행이 촘촘해집니다.
- **숨김 파일**: **⇧⌘.**을 누르거나 **View ▸ Show Hidden Files**를 선택합니다.
- **Settings**(**⌘,**):
  - **General**: 날짜 형식, **Always show file extensions**, **Always show folders first**
  - **Terminal**: **Open in Terminal**에 사용할 앱
  - **Folder Tree**: 트리가 현재 위치를 따라가는 방식
  - **Privacy**: 입력한 주소 기록
  - **Updates**: 업데이트 자동 확인

## 5. Windows 탐색기와 다른 점

| Windows | Explorer for Mac |
|---|---|
| **Ctrl** 단축키 (Ctrl+C, Ctrl+V…) | **⌘(Command)** 단축키 (⌘C, ⌘V…) |
| F2로 이름 바꾸기 | **⌘R**. Mac 노트북에서는 F2가 화면 밝기 키입니다. |
| Backspace로 뒤로 가기 | **Backspace(⌫)**는 상위 폴더로 이동합니다. 뒤로 가기는 **⌘[**입니다. |
| Delete 키로 휴지통에 버리기 | **⌘⌫** 또는 **⌦**로 **휴지통**에 버립니다. **⌫** 단독으로는 삭제되지 않습니다. |
| 휴지통 ▸ 복원 | 휴지통을 열고 **Restore** 선택 |
| F5로 새로 고침 | 폴더가 자동으로 갱신됩니다. 오른쪽 클릭 메뉴에 **Refresh**도 있습니다. |
| 잘라낸 파일을 다른 프로그램에 붙여넣어도 이동 | Explorer 안에서는 잘라내고 붙여넣으면 이동합니다. Finder 등 다른 앱에 붙여 넣으면 복사됩니다. macOS에는 파일 잘라내기 표준이 없기 때문입니다. |
| 드라이브 문자(C:, D:) | 드라이브는 **Locations**에 이름으로 표시되며, 경로는 `/`로 시작합니다. |
