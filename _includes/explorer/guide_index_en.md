# Explorer for Mac User Guide

Explorer for Mac is a macOS file manager for people who are used to Windows File Explorer. If you're new, start with **Getting Started**.

## Guides

- **[Getting Started](/explorer/guide/getting-started/)** — installing, a tour of the window, everyday tasks, and how it differs from Windows Explorer
- **[Keyboard Shortcuts](/explorer/guide/shortcuts/)** — every shortcut, with its Windows Explorer equivalent
- **[Using Explorer Pro](/explorer/guide/pro/)** — how to use each Pro feature
- **[License Guide](/explorer/guide/license/)** — buying, activating, moving to a new Mac, and refunds
- **[FAQ](/explorer/guide/faq/)** — permissions, network drives, updates, and troubleshooting
