# 키보드 단축키

Explorer for Mac은 Windows 탐색기에서 익숙한 단축키를 그대로 쓰되, **Ctrl** 대신 **⌘(Command)**를 사용합니다. 아래 표에는 앱의 모든 단축키와 그에 대응하는 Windows 11 파일 탐색기 단축키를 정리했습니다. "—"는 Windows에 해당하는 단축키가 없다는 뜻입니다.

기호: **⌘** Command · **⇧** Shift · **⌥** Option · **⌃** Control · **↩** Return · **⌫** Delete(Backspace) · **⌦** 앞으로 삭제(fn + Delete) · **⇥** Tab · **↑ ↓** 화살표 키

**(Pro)** 표시가 있는 단축키는 [Explorer Pro](/explorer/guide/pro/)에서 사용할 수 있습니다.

## 탐색

| 동작 | Explorer for Mac | Windows 탐색기 |
|---|---|---|
| 선택한 폴더·파일 열기 | ↩ 또는 ⌘O | Enter |
| 상위 폴더로 이동(**Go ▸ Enclosing Folder**) | ⌘↑ | Alt+↑ |
| 상위 폴더로 이동 | ⌫ | Alt+↑ (Windows에서 Backspace는 '뒤로') |
| 뒤로 | ⌘[ | Alt+← |
| 앞으로 | ⌘] | Alt+→ |
| 주소창에 경로 입력(**Go ▸ Edit Path**) | ⌘L | Ctrl+L 또는 Alt+D |
| 주소창: 입력한 경로로 이동 | ↩ | Enter |
| 주소창: 추천 목록 열기·선택 | ↓ / ↑ | ↓ / ↑ |
| 주소창: 편집 취소 | Esc | Esc |
| 이름으로 항목 찾아가기 | 이름 첫 글자 입력 | 이름 첫 글자 입력 |

## Windows와 다르게 동작하는 키

- **F2(이름 바꾸기)**: **⌘R**을 사용하세요. Mac 키보드에서는 F2가 화면 밝기 키여서 앱에 전달되지 않습니다.
- **Backspace**: 상위 폴더로 이동하며, 절대 삭제하지 않습니다. 뒤로 가려면 **⌘[**를 누르세요.
- **Delete**: **⌘⌫** 또는 **⌦**(노트북에서는 fn + Delete)를 사용하세요.
- **F5(새로 고침)**: 폴더가 자동으로 갱신되므로 필요하지 않습니다. 오른쪽 클릭 메뉴에 **Refresh**도 있습니다.
