# Explorer Pro 라이선스 가이드

Explorer Pro는 **1회 결제(USD 19)로 영구히 사용하는 라이선스**입니다. 구독이 아니며, 계정을 만들 필요도 없습니다. 구매하면 작은 **라이선스 파일**(`.explorerlicense`)을 받게 되고, 이 파일을 앱에 한 번 가져오면 Pro 기능이 켜집니다.

Pro를 구매하지 않아도 무료 버전은 지금 있는 모든 기능을 그대로 계속 사용할 수 있습니다. Pro에 어떤 기능이 있는지는 [Explorer Pro 기능 안내](/explorer/guide/pro/)를 참고하세요.

## 1. 구매하기

1. [Explorer Pro 소개 페이지](/explorer/#pro)에서 구매 버튼을 누릅니다. 앱 안에서는 **Help ▸ Upgrade to Explorer Pro…** 또는 **Explorer ▸ Settings… ▸ Explorer Pro ▸ Upgrade to Pro**를 눌러도 됩니다.
2. 브라우저에서 결제 페이지가 열립니다. 결제는 판매 대행사인 **Lemon Squeezy**가 처리하며, 앱 안에서는 어떤 결제도 이루어지지 않습니다.
3. 결제가 끝나면 구매 확인 이메일로 **라이선스 키**가 발송됩니다. <!-- TODO 확인: Lemon Squeezy 구매 확인 이메일에 라이선스 키가 포함되는지 실제 주문으로 확인 -->

라이선스 키는 `XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX` 형태의 문자열입니다. 나중에 라이선스 파일을 다시 받을 때 필요하므로 이메일을 지우지 말고 보관해 두세요.

무료 버전을 쓰다가 Pro 기능을 실행하면 "**… is an Explorer Pro feature.**"라는 안내가 한 번 나타납니다. 여기서 **Upgrade to Pro…**를 누르면 구매 페이지가, **Import License…**를 누르면 라이선스 가져오기 창이 열립니다. **Cancel**을 누르면 아무 일도 일어나지 않습니다.

## 2. 라이선스 파일 받기

라이선스 키를 라이선스 파일로 바꾸는 과정입니다.

1. [라이선스 발급 페이지](/explorer/activate.html)를 엽니다.
2. **License key** 칸에 구매 이메일의 라이선스 키를 붙여 넣고 **Get license file**을 누릅니다.
3. `Explorer-Pro.explorerlicense` 파일이 내려받아집니다(보통 다운로드 폴더).

같은 키로 **언제든, 몇 번이든 다시 받을 수 있습니다.** 다시 받는다고 해서 사용 횟수가 줄어들지 않습니다.

발급 페이지에서 오류가 나면 다음을 확인하세요.

- **That key wasn't recognized.** — 키를 잘못 입력했을 수 있습니다. 구매 이메일에서 다시 복사해 붙여 넣으세요.
- **This key has been deactivated** — 환불 등으로 비활성화된 키입니다.
- **Too many attempts.** — 짧은 시간에 요청이 너무 많았습니다. 1분쯤 기다렸다가 다시 시도하세요.
- **The license service is temporarily unavailable.** — 잠시 후 다시 시도하세요.

## 3. 앱에서 활성화하기

다음 방법 중 편한 것을 쓰면 됩니다. 결과는 모두 같습니다.

**방법 A — 파일 더블클릭 (가장 간단)**

1. 내려받은 `Explorer-Pro.explorerlicense` 파일을 더블클릭합니다.
2. Explorer가 열리면서 **Explorer Pro Unlocked** 알림과 함께 "Licensed to (이름) (이메일)"이 표시됩니다.

**방법 B — 설정에서 가져오기**

1. 메뉴에서 **Explorer ▸ Settings…**(⌘,)를 엽니다.
2. 맨 아래 **Explorer Pro** 섹션에서 **Import License…**를 누릅니다.
3. 라이선스 파일을 선택합니다.

라이선스 파일을 **Explorer Pro** 섹션 위로 끌어다 놓아도 됩니다. 파일 대신 내용을 붙여 넣으려면 **Or paste your license here** 칸에 붙여 넣고 Return 키를 누르세요. 라이선스 파일은 일반 텍스트이므로 이메일 등으로 받은 내용을 그대로 붙여 넣어도 됩니다.

활성화가 끝나면 **Explorer Pro** 섹션의 **Status**가 **Free**에서 **Licensed to (이름) (이메일)**로 바뀝니다. 앱을 다시 실행할 필요는 없습니다.

**"Not a Valid License"가 나올 때**

파일이 손상되었거나, 일부만 붙여 넣었거나, Explorer Pro용 라이선스가 아닌 경우입니다. [발급 페이지](/explorer/activate.html)에서 라이선스 파일을 다시 받아 가져오세요. 이 오류가 나도 이미 활성화된 라이선스는 그대로 유지됩니다.

## 4. 여러 대의 Mac에서 사용하기

Pro 라이선스는 **구매자 본인 1인**에게 부여되며, 본인이 소유하거나 사용하는 Mac이라면 **대수 제한 없이** 사용할 수 있습니다. 개인 용도와 업무 용도 모두 허용됩니다. 자세한 내용은 [이용약관](/explorer/terms/) 제4조를 참고하세요.

다른 Mac에서도 같은 라이선스 파일을 위 3장과 같은 방법으로 가져오면 됩니다. 라이선스는 특정 기기에 묶이지 않습니다.

다만 라이선스 파일이나 키를 다른 사람에게 공유하는 것은 허용되지 않습니다. 여러 사람이 Pro를 사용하려면 사람마다 라이선스가 필요합니다.

## 5. 새 Mac으로 옮기거나 다시 설치할 때

- **앱을 업데이트하거나 다시 설치하는 경우**: 라이선스는 앱과 별도로 Mac에 저장되어 있어서, 보통 다시 가져올 필요가 없습니다. <!-- TODO 확인: 앱 삭제 후 재설치 시 ~/Library/Application Support/io.yjlab.Explorer/license 유지되어 Pro 상태가 복원되는지 실제 확인 -->
- **새 Mac으로 옮기는 경우**: 새 Mac에 Explorer를 설치한 뒤 라이선스 파일을 더블클릭하거나 **Import License…**로 가져오세요.
- **라이선스 파일이 없는 경우**: [발급 페이지](/explorer/activate.html)에서 같은 라이선스 키로 다시 받으면 됩니다.

라이선스 파일을 클라우드 드라이브나 비밀번호 관리자에 백업해 두면 다음부터 더 편합니다.

## 6. 라이선스 키를 잃어버렸을 때

1. 먼저 구매 당시 이메일 받은편지함에서 **Lemon Squeezy**가 보낸 구매 확인 이메일을 찾아보세요.
2. Lemon Squeezy의 주문 내역 페이지에서도 키를 확인할 수 있습니다. <!-- TODO 확인: Lemon Squeezy 구매자용 주문 페이지(My Orders)에서 라이선스 키가 표시되는지와 그 URL -->
3. 그래도 찾을 수 없다면 support@yjlab.io로 **주문번호 또는 구매 시 사용한 이메일**을 알려 주세요. 구매를 확인한 뒤 라이선스 파일을 다시 보내 드립니다.

## 7. 라이선스 제거하기

1. **Explorer ▸ Settings…**를 엽니다.
2. **Explorer Pro** 섹션에서 **Remove License**를 누릅니다.

확인 창 없이 바로 제거되며, Pro 기능도 즉시 꺼지고 무료 버전으로 돌아갑니다. 무료 기능은 그대로 계속 사용할 수 있습니다. 나중에 라이선스 파일을 다시 가져오면 Pro가 다시 켜집니다.

## 8. 환불

구매일로부터 **14일 이내**라면 사유를 묻지 않고 전액 환불해 드립니다. 신청 방법과 기준은 [환불정책](/explorer/refund/)을 참고하세요.

환불이 완료되면 라이선스 키가 비활성화되어 라이선스 파일을 다시 받을 수 없고, 라이선스 사용 권한도 종료됩니다. 위 7장의 방법으로 라이선스를 제거해 주세요.

## 9. 오프라인 동작과 개인정보

- **앱은 라이선스 확인을 위해 서버에 접속하지 않습니다.** 라이선스 파일은 Ed25519 전자서명이 되어 있고, 앱은 내장된 공개키로 Mac 안에서만 이를 검증합니다. 인터넷이 없어도 Pro 기능은 그대로 동작합니다.
- **만료일이 없습니다.** 앱은 라이선스 확인에 시스템 시계를 사용하지 않으므로, 날짜를 바꾸거나 오랫동안 오프라인으로 지내도 라이선스가 풀리지 않습니다.
- **서버에 의존하지 않습니다.** 앞으로 배포가 중단되더라도 이미 활성화된 Pro 기능은 해당 버전의 앱에서 계속 사용할 수 있습니다.
- **라이선스 파일에 담긴 정보**는 구매 시 입력한 이름, 이메일, 주문번호뿐이며, 이 정보는 Mac에만 저장됩니다.
- 인터넷 연결이 필요한 것은 결제할 때와 [발급 페이지](/explorer/activate.html)에서 라이선스 파일을 받을 때뿐이며, 둘 다 앱이 아닌 브라우저에서 이루어집니다. 발급 서버는 라이선스 키를 확인한 뒤 개인정보를 저장하지 않습니다.

자세한 내용은 [개인정보처리방침](/explorer/privacy/)을 참고하세요.
