# YomiClaw 개인정보 처리방침

**시행일자: 2026-06-01**
**최종 수정일자: 2026-06-01**

YomiClaw(이하 "앱")는 사용자의 개인정보를 소중히 다루며, 「개인정보 보호법」 및 관련 법령을 준수합니다. 본 방침은 앱이 사용자 정보를 어떻게 수집·이용·보관하는지 안내합니다.

---

## 1. 수집하는 정보 및 수집 방법

본 앱은 **별도의 회원가입이 없으며, 사용자의 개인정보를 서버로 전송하거나 저장하지 않습니다.** 다음 정보는 기기 내에서만 처리되며 외부로 전송되지 않습니다.

| 항목 | 처리 방식 | 사용 목적 |
|---|---|---|
| 마이크 입력(음성) | 실시간 처리, 저장하지 않음 | 음성 번역 |
| 음성 인식 결과(텍스트) | 기기 내 SwiftData 에 로컬 저장 | 대화 기록 표시 |
| 위치 정보(현재 위치) | 기기 내에서만 사용, 저장하지 않음 | 현재 장소에 맞는 번역 프리셋 추천 |
| 카메라 영상 | 실시간 처리, 저장하지 않음 | 메뉴판·간판 텍스트 인식 |
| 번역 결과 텍스트 | 기기 내 SwiftData 에 로컬 저장 | 대화 기록 표시 |
| 사용자 설정(언어, 음성 등) | 기기 내 UserDefaults 에 로컬 저장 | 사용자 환경 유지 |

---

## 2. 외부 통신

본 앱은 아래의 경우에만 네트워크 통신을 수행하며, 사용자가 입력한 음성·텍스트·이미지는 **전송 대상이 아닙니다.**

- **언어 모델 다운로드** — 앱 최초 실행 시 또는 모델 업데이트 시, AI 번역·응답 추천에 사용되는 언어 모델 파일을 Hugging Face Hub(`huggingface.co`)에서 다운로드합니다. 다운로드된 모델은 기기 내에 저장되어 이후 오프라인 동작이 가능합니다.
- **Apple Translation 언어팩 다운로드** — 최초 사용 시 Apple 의 번역 언어팩을 다운로드합니다(Apple 의 시스템 기능).
- **Apple 음성 인식** — iOS 시스템 음성 인식(`SFSpeechRecognizer`)을 사용합니다. 본 앱은 해당 언어가 기기 내 인식을 지원하는 경우 **`requiresOnDeviceRecognition = true`** 로 설정하여 음성 데이터를 Apple 서버로 전송하지 않고 기기 내에서만 처리합니다. 사용자의 기기·OS 버전이 해당 언어의 기기 내 인식을 지원하지 않는 예외적인 경우에 한해 Apple 의 [음성 인식 및 개인정보 보호](https://support.apple.com/ko-kr/HT210657) 정책에 따라 서버 인식으로 동작할 수 있으며, 이 경우에도 본 앱 운영자는 해당 데이터에 접근할 수 없습니다.

본 앱은 별도의 분석 SDK, 광고 SDK, 크래시 리포팅 SDK 를 사용하지 않습니다.

---

## 3. 개인정보의 보관 및 삭제

- 모든 대화 기록·설정 정보는 **사용자 기기 내에만 저장**되며, 운영자는 접근할 수 없습니다.
- 사용자는 앱 내 "휴지통" 기능으로 대화 기록을 언제든 삭제할 수 있습니다.
- 앱을 삭제하면 기기에 저장된 모든 데이터(대화 기록, 설정, 다운로드된 모델 파일)가 함께 삭제됩니다.

---

## 4. 제3자 제공 및 위탁

본 앱은 사용자 정보를 제3자에게 제공하거나 처리 위탁하지 않습니다. 단, 제2조에 명시된 시스템 기능(Apple 음성 인식, Apple Translation, Hugging Face Hub) 사용 시에는 각 제공자의 정책이 적용됩니다.

---

## 5. 이용자의 권리

이용자는 앱 내 설정 메뉴 및 iOS 시스템 설정을 통해 언제든 다음 권리를 행사할 수 있습니다.

- 카메라·마이크·음성 인식·위치 접근 권한 철회 (iOS 설정 → YomiClaw)
- 대화 기록 전체 삭제 (앱 내 휴지통)
- 앱 삭제를 통한 모든 로컬 데이터 제거
